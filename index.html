  • Study detects AI coding agents across open-source repositories

    AI 2026-06-25
    A new arXiv paper says generative AI coding agents are already leaving measurable traces in the open-source software supply chain, but standard detection methods miss most of the activity. Researchers Arsham Khosravani and Audris Mockus introduced a multi-method census across World of Code’s 180 million-plus Git repositories, combining configuration-file scans, commit-message analysis, author-identity matching and bot-signature lookup [1]. In one snapshot, the approach identified 850,157 Claude Code commits, while bot-account lookup found only 28,154, or 3.3%, a 30x relative-recall gap [1]. The paper says commit-attributed agents generated more than 320,000 commits per month across snapshots from December 2024 to April 2026 [1]. Project pages reviewed for the story described developer tools for agent operations: Hezo offers self-hosted teams of agents with secret isolation, Zedra provides remote control for coding agents, swarm-test analyzes multi-agent topology before production, and OntoCortex separates typed LLM intent from deterministic execution [4][6][8][11]. Other projects focused on reducing LLM bills and choosing models. AI Gateway claims semantic caching can cut LLM API costs by 40%-70%, Cascade says its C++ proxy routes predictable prompts to cheaper models after 4.59 milliseconds of tokenization, embedding and prediction, Wayfinder Router makes offline prompt-complexity routing decisions without an LLM call, and ModelFit runs repository-specific coding probes to find cheaper backup models for a codebase [5][16][18][15].
