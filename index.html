  • Nvidia releases PAIR for local AI clusters

    AI 2026-09-05
    Nvidia released PAIR, a free, open-source beta tool that links compatible home computers into a local AI inferencing cluster through a single interface, following the software's announcement at IFA 2026 in Berlin [3][5][6][8][12]. The Personal AI Router works across Windows, macOS and Linux systems and can connect RTX-equipped PCs, DGX Spark machines and supported Macs to distribute AI workloads across devices on a local network [5][6][13][14]. PAIR addresses a local AI bottleneck: AI agents and chatbot workflows can generate multiple independent inference requests that queue on one machine, so the software routes separate jobs to available devices instead of requiring a cloud service or a dedicated server [3][5][10][11]. Nvidia describes PAIR as a router, not an inference engine; Ollama or LM Studio still run the models, while PAIR selects where requests go and returns results to the user [5][8][13][14]. The tool keeps prompts, files and agent context inside the local network, a design for users who want local AI processing without sending data to cloud services [3][5][10][13]. Nvidia and early coverage also stress a key limitation: PAIR does not merge several GPUs into one virtual accelerator or combine VRAM, so a model that exceeds a single device’s memory still will not run solely because several computers are connected [6][10][13].

  • UN backs Equal Earth map in 164-1 vote

    World 2026-09-05
    The United Nations General Assembly voted Friday, September 4, to endorse a Togo-sponsored, African Union-backed resolution encouraging wider use of world maps that show continents in more accurate relative proportions, including the 2018 Equal Earth projection [4][9][14][7]. The measure passed 164 to 1, with the United States casting the only vote against it and six countries abstaining [1][4][9][14][17].
