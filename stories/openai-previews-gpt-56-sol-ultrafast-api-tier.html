OpenAI previews GPT-5.6 Sol Ultrafast API tier

Category: AI

OpenAI previewed Ultrafast, a new OpenAI API service tier that runs GPT-5.6 Sol at up to 14 times the speed of standard processing and can generate up to 750 output tokens per second [4][1][2][5][7][6][8][9][11]. The preview launched initially for select customers, with OpenAI saying access will expand as capacity grows [4][2][5][7][6][8][11]. OpenAI and Cerebras said the tier is intended to bring the company’s most capable GPT-5.6 model to low-latency workflows where teams previously often chose smaller or specialized models for speed [1][2][7][11]. OpenAI listed incident response, customer support, financial market analysis, e-commerce, security, voice, research and developer-agent use cases among the initial targets [1][2][5][7][8].

Primary Source: View original article

Key Points

  • Limited access: Businesses can join the waitlist by sharing workload details, latency requirements, expected usage and other deployment information [5][8].
  • Benchmark claim: Cerebras said GPT-5.6 Sol Ultrafast completed all 2,500 Humanity’s Last Exam questions in 11 hours and 11 minutes, compared with 78 hours and 27 minutes for Claude Fable 5 at comparable accuracy [11][9].
  • Existing tier: Habr reported that the existing Fast API mode speeds GPT-5.6 Sol by up to 2.5 times and costs twice the Standard rate, while OpenAI has not disclosed Ultrafast pricing [9].
  • Internal use: OpenAI developers have used Ultrafast to analyze logs and traces during incidents and compress research cycles that previously ran overnight into multiple same-day iterations [5][8].

Perspectives

Cerebras: Cerebras said it powered the tier without a quality compromise and said memory bandwidth, not only compute, is a key bottleneck for large-model inference speed.

Sources: Cerebras

The Next Web: The Next Web said the launch reflects a bet that latency will shape whether AI agents feel usable in real products, not just demos.

Sources: The Next Web

Timeline

  • June 2026: OpenAI introduced GPT-5.6 Sol, Terra and Luna [5][8].
  • July 2026: The GPT-5.6 family became broadly available across ChatGPT, Codex and API [5][8].
  • 13 August 2026: OpenAI opened the Ultrafast preview for select API customers [2][7].

Technical Details

  • Output-token throughput: Ultrafast can generate up to 750 output tokens per second; output tokens are the discrete text pieces an LLM produces during a response [4][1][2].
  • Wafer-scale inference: Habr reported that Cerebras’s Wafer-Scale Engine keeps model weights on-chip with 44 GB of SRAM per wafer-scale chip and streams data through layers distributed across multiple wafers to reduce movement between compute units and external memory [9].

Industry Impact

  • AI inference hardware: Cerebras positioned memory bandwidth as a major inference-speed constraint for large models on GPUs and said its wafer-scale architecture reduces data movement by keeping weights on-chip [9].
