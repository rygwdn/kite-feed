AI developers launch security, benchmarking and tooling projects

Category: AI

Several AI developer projects published or surfaced between Aug. 15 and Aug. 16, offering infrastructure for LLM security audits, model routing, coding-agent verification, local dictation, watermark analysis, model-price discovery and SaaS discovery workflows [7][8][3][5][11][4][6]. The Rails Foundation also published initial results from Agents on Rails, an ongoing benchmark project commissioned from Evil Martians to measure agentic coding tools on Ruby on Rails codebases [9]. The projects include Sentinel Scan, which offers a $249 authorized red-team audit for LLM apps; ProofRun, which creates local verification receipts for AI coding-agent test claims; Dictata, which runs system-wide voice dictation locally on Windows; WMTrace, which analyzes declared LLM watermark schemes; FreeLLMAPI, which offers one OpenAI-compatible key for free-model routing; and TokenLab MCP, which lets MCP clients query models, compare pricing and call text or multimodal tools [7][3][5][11][8][4]. SaaSLyra presents structured product listings aimed at discovery through search engines and AI answer surfaces [6].

Primary Source: View original article

ProofRun doesn't judge whether your code is correct. It proves — cryptographically, not by asking nicely — which checks actually ran against the exact code you have right now.

— ProofRun project README (GitHub)

Key Points

  • Rails benchmark: Agents on Rails will roll out in stages over several weeks and aims to compare model output quality, token costs and frontier-versus-open-weight tradeoffs for Rails tasks [9].
  • Audit pilot: Sentinel Scan said its first-party pilot ran 15 prompt-injection and data-exfiltration attacks, found 0 vulnerabilities and averaged $0.0013 in LLM cost per scan [7].
  • Model access: FreeLLMAPI lists 343 models across 27 providers and says its catalog tracks about 4 billion free tokens per month behind a self-hosted, OpenAI-compatible router [8].
  • Tool coverage: TokenLab MCP enables 31 default tools and can expand to 80, with model and pricing lookup available without an API key [4].
  • Local workflow: Dictata says it uses whisper.cpp locally, supports Vulkan GPU or CPU transcription and can route cleanup through a local OpenAI-compatible LLM [5].

Technical Details

  • Proof receipts: ProofRun marks a check as stale after code changes, tying the reported result to the exact code state instead of relying on an agent's textual claim [3].
  • Watermark scope: WMTrace separates watermark detection, generic AI-text detection, model attribution and provenance verification into different namespaces and reports calibrated statistics such as z-scores and Holm-adjusted p-values [11].
  • MCP profiles: TokenLab MCP uses a core profile for 31 common tools and a full profile for 80 tools, with the profile set through the TOKENLAB_MCP_TOOL_PROFILE environment variable [4].

Historical Background

OpenAI-compatible APIs have become a common integration target for third-party AI tools because they let applications swap model providers with fewer code changes [common]. The Model Context Protocol, introduced by Anthropic in 2024, created a standard way for AI assistants to connect with external tools and data sources [common].

Action Items

  • Verify AI coding-agent test claims: Run project checks through ProofRun so later code edits mark old passing results as stale instead of relying on a chat transcript [3].
  • Limit public exposure of model routers: FreeLLMAPI says the proxy is built for personal use only and should not be exposed publicly [8].
