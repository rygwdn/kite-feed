Apple patches iPhone flaw that exposed deleted Signal notifications

Category: Technology

Apple has released iOS 26.4.2 and iPadOS 26.4.2, along with iOS 18.7.8 and iPadOS 18.7.8 for older devices, to fix a Notification Services flaw that could leave deleted notifications stored on an iPhone or iPad [2][3][7][8][17]. Apple said notifications marked for deletion could be unexpectedly retained on the device and that it fixed the issue with improved data redaction [1][15][17]. The update drew attention because recent reporting and court testimony showed the FBI had forensically extracted Signal message previews from an iPhone even after the Signal app was deleted, with the retained data coming from the device's local notification database rather than any break in Signal's encryption [1][2][4][13][10]. The good news for users is simple: Apple has now closed the gap, and several reports urged eligible iPhone and iPad owners to install the update to reduce their exposure to the flaw [1][5][9].

Primary Source: View original article

Did you know: According to Macworld's review of Apple's update cadence, this was the first iOS 26 release to get a second mid-cycle update [15].

Key Points

  • Affected setup: The messages were recoverable when Signal previews were allowed on the Lock Screen, because the message content shown in notifications was stored locally on the device [2][13].
  • CVE assigned: Mashable and The Hacker News identified the patched bug as CVE-2026-28950, and Apple said the issue was in Notification Services [12][17][15].
  • Signal workaround: Before Apple issued the fix, Signal CEO Meredith Whitaker advised users to disable notification content so alerts would not show the sender's name or message text [1].
  • Next software: MacRumors said Apple is already beta testing iOS 26.5 and iPadOS 26.5, which are expected to arrive later in May [3][15].

Perspectives

Apple: Apple described the issue as a logging problem in Notification Services and said improved data redaction now stops notifications marked for deletion from being unexpectedly retained on devices.

Sources: Macworld

Signal: Signal welcomed the patch and had already urged users to choose more private notification settings so incoming alerts would not expose sender names or message content.

Sources: Engadget

Electronic Frontier Foundation: The EFF argued that notification privacy is vulnerable both in the cloud, where providers may log metadata, and on the device, where local storage can preserve sensitive content longer than users expect.

Security analysts and reporters: Coverage from 404 Media, Schneier, and others emphasized that forensic extraction can uncover data from secure messaging apps in operating-system databases even when the encrypted app itself was not compromised.

Timeline

  • 2023: Apple begins requiring court orders for notification data requests [1]
  • 8 April 2026: Apple releases iOS 26.4.1 before the newer security fix [3][8]
  • 22 April 2026: Apple ships iOS 26.4.2, iPadOS 26.4.2 and 18.7.8 updates [2][3][7]
  • 23 April 2026: Additional reports detail FBI extraction and the patch's privacy implications [4][12][9]

Technical Details

  • Notification database retention: The flaw involved the operating system's notification storage layer keeping records that had been marked for deletion, meaning message previews could persist in local device storage after the user expected them to disappear [1][15][17].
  • Improved data redaction: Apple said it fixed the bug with improved data redaction, which suggests the remediation targeted how notification data is logged or scrubbed inside Notification Services rather than changing Signal's encryption model [2][7][12].
  • Forensic extraction path: The case illustrates a side-channel risk in mobile forensics: investigators with physical access to a device can extract artifacts from system databases, so security depends not only on an app's cryptography but also on how the operating system handles previews and deleted records [13][4].

Industry Impact

  • Secure messaging: The incident underscored that encrypted apps such as Signal can still expose message previews through operating-system notifications, prompting renewed attention to safer default notification settings [1][13][12].
  • Mobile forensics: Court testimony and follow-up reporting showed that investigators could use forensic tools to mine operating-system artifacts rather than break app encryption directly, a notable reminder for digital evidence workflows [4][13][10].
  • Device support: Apple issued parallel fixes for iOS 26, iPadOS 26, and the older iOS 18 and iPadOS 18 branches, showing continued security maintenance for legacy hardware still in use [2][7][8].

Historical Background

Apple has long positioned privacy as a core product feature [common]. Engadget reported that since 2023, Apple has required a court order to share notification data, which makes this local-retention flaw notable because it created another way for investigators to access message previews without breaking Signal's end-to-end encryption [1]. The current case also highlights a longstanding security reality: data exposed in lock-screen notifications can outlive the app session, or even the app itself, if the operating system does not fully delete it [13][common].

Action Items

  • Install the latest Apple update: On an eligible iPhone or iPad, open Settings, tap General, then Software Update, and install iOS 26.4.2, iPadOS 26.4.2, or 18.7.8 for older devices [3][2].
  • Limit notification previews: If you use Signal or other secure messengers, change notification settings so alerts do not display sender names or message content on the Lock Screen [1][13].
