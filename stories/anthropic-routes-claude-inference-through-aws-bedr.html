Anthropic routes Claude inference through AWS Bedrock in India

Category: AI

Anthropic has made Claude requests available for in-country inference in India through Amazon Bedrock, allowing those requests to be processed within India [1][2][3][4]. The rollout was reported on Oct. 5, 2026, with coverage describing Claude as live in India on the AWS service [5][6]. The development gives organizations using Amazon Bedrock an India-based route for Claude inference [2][6].
