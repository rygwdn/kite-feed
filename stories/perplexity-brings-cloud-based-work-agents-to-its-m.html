Perplexity brings cloud-based work agents to its Mac app

Category: AI

Perplexity has added its multi-agent task system, Teammates, to its Mac app, letting users run cloud workflows through connected work apps without keeping their computers awake [7]. Users can delegate ongoing work to agents that break goals into tasks, coordinate parallel work and return results for review [7][8]. The Mac app provides a desktop interface for a system Perplexity first introduced on its website, where agents can retain project context and hand work to one another [8]. The system remains a research preview for individual Max subscribers. Agents use a monthly credit allocation, and Perplexity warns that parallel runs, large files or frequent automations can use more credits [7]. The company has not specified when a promotional allowance for Max users ends [7].

Primary Source: View original article

Key Points

  • Model choice: New teammates use Claude Opus 5.5 by default, while users can select a different model for each agent [7].
  • Competing designs: LavX says Meta Muse and ChatGPT Dots rely on a single chat model rather than multiple agent instances; Digital Trends describes Grok Bot as a cloud agent that works without constant prompting [1][2].
  • Documentation lag: Perplexity’s Help Center still describes Teammates as running on its website and does not mention the Mac app [7].
  • Slack collaboration: Adding a teammate to a Slack channel lets colleagues assign work or ask for updates [8].

Timeline

  • 4 November 2026: Perplexity announced Teammates for web-based Max subscribers [8]
  • 5 November 2026: Chief executive Aravind Srinivas said native mobile and desktop apps were coming [7]
  • 13 November 2026: Perplexity announced Teammates availability in its Mac app [7][5]

Technical Details

  • Isolated agent environments: Each teammate has its own role, desktop and browser [7].
  • Connected-tool permissions: Agents monitor connected services such as Slack, GitHub and Linear through installed plugins, and GitHub access can be restricted to selected repositories [7][8].

Q&A

Q: Can users intervene while a teammate is working?

A: Yes. Users can inspect the work, take over the desktop or redirect an agent while it is running [8].
