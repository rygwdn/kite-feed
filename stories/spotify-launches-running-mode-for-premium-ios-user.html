Spotify launches Running Mode for Premium iOS users

Category: Technology

Spotify launched Running Mode on July 30, 2026, adding personalized workout playlists for Premium subscribers using iOS in the U.S., Canada, the U.K., Ireland, Australia, New Zealand and Sweden [14][4][5][12]. Users can choose from 25 running presets in Spotify’s Fitness Hub and customize workout type, duration, beats per minute and preferred music style [14][2][9][13]. Running Mode creates playlists around a user’s selected tempo, music taste and workout structure, with supported session types including steady runs, intervals and pyramid workouts [14][5][8]. Spotify said the feature builds on Prompted Playlists after fitness requests became one of the most popular uses of that playlist-generation system [2][3][7][13]. The mode includes optional English-language audio cues that guide runners through workout stages without stopping the music [14][4][8][13]. Spotify has not announced Android availability for Running Mode, while User Notes rolled out separately for users on Android and iOS in select markets [3][10].

Key Points

  • User Notes: The feature lets listeners add public-facing text comments to tracks in personal playlists, with visibility extending to shared playlists created by the note author [3][10].
  • Personalization question: PCMag said Spotify had not confirmed whether Running Mode uses likes, dislikes and listening history, despite describing the feature as personalized [12].

Perspectives

Spotify: Spotify said Running Mode 'helps you spend less time hunting for the right music and more time moving,' and said fitness prompts were among the most-used Prompted Playlist requests.

Sources: Spotify Newsroom

Spider’s Web: Spider’s Web criticized the initial country list from a Polish user perspective, noting that Running Mode was not available in Poland at launch.

Sources: Spider’s Web

Timeline

  • 2015: Spotify introduced pace-detecting running mode using phone sensors [15][18].
  • 26 February 2018: Spotify removed the original running feature from the app [18].
  • April 2026: Spotify added Peloton classes and creator workout videos [5][7].
  • 30 July 2026: Spotify launched Running Mode for Premium iOS users [14].

Industry Impact

  • Fitness apps: Spotify’s move follows Strava’s discontinuation of its in-app Spotify integration late last month, when Strava removed music controls from its workout display that had been available since 2023 [5].
  • Workout content: Spotify added Peloton classes and creator workout videos to the app earlier in 2026, and iphone-ticker reported that Spotify’s Fitness area included more than 1,400 Peloton courses [7][15].

Historical Background

Spotify introduced an earlier running mode in 2015 that used phone movement to detect a runner’s pace and adjust music automatically [15][18]. Spotify discontinued that original feature in 2018 and pointed users to standard playlists with fixed tempo labels as an alternative [15]. The 2026 version differs because users choose their target workout type, duration and tempo rather than relying on automatic cadence detection [15][18].
