Researchers expose reasoning traces in major AI APIs

Category: AI

Researchers said they found a way to extract hidden chain-of-thought reasoning from proprietary large language model APIs by replaying encrypted reasoning blocks through weaker models in the same provider ecosystem [2][3][8][9]. The researchers demonstrated the technique across OpenAI, Anthropic and Google systems, including Claude, GPT and Gemini model families [6][2][3][8]. The paper says major providers hide step-by-step reasoning to protect intellectual property and limit information leakage, but send encrypted reasoning blocks back to client applications for use in later requests rather than storing all traces server-side [2][8]. The researchers said the flaw arose because those encrypted blocks were compatible across sessions, users and models within a provider’s ecosystem, allowing a less safeguarded model to output another model’s reasoning in plaintext [2][3][8]. The research team reported four attack vectors: bypassing anti-distillation protections, extracting private data from publicly shared logs, revealing hazardous information hidden in rejected responses and enabling invisible prompt injections inside encrypted blocks [2].

Key Points

  • Access requirements: CyberSecurityNews said the attack required only standard, unprivileged API access, not access to provider infrastructure or privileged credentials [8].
  • Research team: CyberSecurityNews identified the work as a collaboration involving the ELLIS Institute Tübingen, the Max Planck Institute, MATS Research and Snyk [8].
  • Provider response: AI-Updates said the researchers notified OpenAI, Anthropic and Google, and that all three adjusted their APIs before publication [3].
  • Model lineage: WIRED reported that researchers cited extracted traces in saying some Chinese AI systems may have been trained on leading U.S. models [6].

Timeline

  • 10 August 2026: Paper submitted to arXiv detailing reasoning-trace theft [2]
  • 11 August 2026: WIRED published article on extracting Claude, GPT and Gemini traces [6]
  • 11 August 2026: CyberSecurityNews described cross-model replay against major AI APIs [8]
  • 12 August 2026: Firstpost reported hidden reasoning risk and distillation concerns [9]

Technical Details

  • Cross-model replay: The attack reuses an encrypted reasoning envelope generated by a more capable model as input to a cheaper sibling model in the same provider ecosystem, turning that weaker model into a decryption oracle that emits the trace in plaintext [2][8].
  • Missing cryptographic binding: CyberSecurityNews reported that encrypted payloads used a provider-wide authentication approach rather than being bound to a specific account, session ID or model tier, which allowed valid replay across models under the same provider [8].
  • Invisible prompt injection: The paper says malicious instructions can be embedded entirely inside encrypted reasoning blocks, letting attackers influence later model behavior without visible prompt text in the client-facing conversation [2].

Industry Impact

  • Model lineage controversy: AI-Updates noted that exposed reasoning traces can be used to compare how closely one model’s reasoning resembles another’s, raising questions about training data provenance and potential copying between model developers. [3]
  • Developer operations: The paper said developers often shared session logs publicly without realizing encrypted reasoning blocks could contain recoverable sensitive material [2].
  • Competitive model training: The reported anti-distillation bypass could let competitors study or reuse proprietary reasoning patterns from frontier models, according to the arXiv paper and Firstpost [2][9].

Action Items

  • Audit public AI logs: Search public repositories and issue trackers for saved API session logs, then remove encrypted reasoning blocks or credentials before reuse or publication [2].
  • Rotate exposed secrets: If AI API logs were published, rotate API keys, passwords and tokens that may have appeared in session data, because the researchers recovered credentials from decoded public reasoning blocks [2].
  • Check provider guidance: Review OpenAI, Anthropic and Google API security notices or changelogs for mitigations tied to encrypted reasoning context handling [3].
