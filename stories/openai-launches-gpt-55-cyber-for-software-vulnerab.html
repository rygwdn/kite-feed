OpenAI launches GPT-5.5-Cyber for software vulnerability fixes

Category: AI

OpenAI expanded its Daybreak cybersecurity program on June 22 with GPT-5.5-Cyber, an updated Codex Security plugin, a Cyber Partner Program and Patch the Planet, a project with Trail of Bits to help open-source maintainers find, validate and fix software vulnerabilities [2][3][13][6]. OpenAI said GPT-5.5-Cyber will go to trusted defenders for authorized cybersecurity work, including large-codebase analysis, controlled validation, patch development and testing [2][13][8]. The company said the release shifts attention from vulnerability discovery to remediation, with maintainers facing more reports and limited time and resources [3][6][13]. Patch the Planet starts with projects including cURL, NATS Server, pyca/cryptography, Sigstore, aiohttp, the Go project, freenginx, Python and python.org, with Trail of Bits engineers reviewing findings before they reach maintainers and helping develop patches and tests [3][13]. IBM separately joined OpenAI’s Daybreak Cyber Partner Program and launched an application security service that uses OpenAI cyber capabilities inside enterprise workflows to identify and validate software vulnerabilities [20][19][21]. IBM said the service uses IBM Consulting Advantage to connect client application environments to advanced AI with read-only access to code repositories, bounded execution and controls intended to keep analysis inside the client environment [20].

Did you know: The name Patch the Planet echoes “Hack the Planet,” a catchphrase from the 1995 film “Hackers” [6].

Key Points

  • Benchmark results: Cybersecurity News reported GPT-5.5-Cyber scored 85.6% on CyberGym, 39.5% on ExploitGym and 69.8% on SEC-bench Pro, outperforming GPT-5.5 on all three listed tests [14].
  • Scanner scale: Since its March research preview, Codex Security scanned more than 30 million commits across more than 30,000 codebases, with reviewers marking more than 70,000 findings as fixed and more than 500,000 findings automatically detected as fixed [8][14][5].
  • Sprint output: Trail of Bits organized a five-day opening sprint with 25 engineers; OpenAI and Trail of Bits said the sprint found hundreds of bugs and produced dozens of patches in the first week [15][14].

Timeline

  • March 2026: Codex Security entered research preview before broader Daybreak expansion [8].
  • 22 June 2026: OpenAI published Daybreak tools and Patch the Planet announcements [2][3].
  • 23 June 2026: IBM partnership coverage followed OpenAI’s Daybreak Cyber Partner Program launch [19][21].

Technical Details

  • Codex Security outputs: The plugin can generate reports with severity, affected code locations, validation evidence and remediation guidance, and it can export results through SARIF and CodeQL queries for vulnerability-management workflows [8][14].
  • Controlled validation: OpenAI described GPT-5.5-Cyber as validating vulnerabilities in controlled environments before developing and testing patches, a workflow intended to distinguish exploitable findings from scanner noise [2][13].
  • Benchmark scope: Habr described CyberGym as measuring whether an agent can reproduce known vulnerabilities in a real environment, while noting that the reported GPT-5.5-Cyber lead over Anthropic’s Mythos 5 on that benchmark was 1.8 percentage points [23].

Industry Impact

  • Open-source maintenance: Patch the Planet assigns security engineers to review findings before maintainers receive them, addressing complaints that AI-generated vulnerability reports have increased triage workload [3][6][15].
  • Security vendor adoption: Check Point Software integrated OpenAI cyber capabilities into its security platform, extending the Daybreak Cyber Partner Program to another major enterprise security provider [10].
  • Bug-bounty ecosystem: OpenAI named HackerOne and Calif as collaborators for vulnerability triage and coordinated disclosure in the Patch the Planet program [8][14][15].

Historical Background

OpenAI introduced Daybreak in May 2026 as a cybersecurity initiative before expanding it in June with GPT-5.5-Cyber, Codex Security updates and Patch the Planet [13]. The Log4j vulnerability, disclosed in 2021, showed how a flaw in a widely used open-source component can affect commercial software at large scale [6][common].

Business Angle

  • IBM may benefit more from services revenue and workflow integration than from model performance itself because enterprise cybersecurity buyers often pay for implementation, governance and support [20][common].
  • OpenAI’s limited-access approach reduces misuse risk but may slow broad monetization compared with general developer tooling [2][8][common].
  • Open-source remediation can create indirect value for commercial software companies by lowering dependency risk without requiring every vendor to patch upstream code alone [6][common].

International Reactions

  • 🇺🇸🇬🇧 United States and United Kingdom governments: ETNews reported OpenAI expanded Trusted Access for Cyber partnerships with the U.S. and U.K. governments [22].
  • 🇪🇺 European Union cybersecurity agency: ETNews reported OpenAI also partnered with the European Union cybersecurity agency under Trusted Access for Cyber [22].
  • Korea, Japan, Canada, Australia, Germany and France: ETNews reported OpenAI listed these governments among its Trusted Access for Cyber partners [22].

Action Items

  • Audit open-source dependencies: Identify whether your software depends on projects named in Patch the Planet, such as cURL, Python, Go, Sigstore or pyca/cryptography, and track their security advisories and patch releases [3][13].
  • Review AI-scanner intake rules: Require validation evidence, affected code locations and remediation guidance before routing AI-generated vulnerability reports to maintainers or engineering teams [8][13].
