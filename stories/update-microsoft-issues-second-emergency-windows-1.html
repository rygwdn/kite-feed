Update: Microsoft issues second emergency Windows 11 patch

Category: Technology

Microsoft has released a second out-of-band Windows 11 update to address Outlook crashes and related app hangs that appeared after its January 2026 security update [1][3]. The company says the bug could make some apps that open or save files in cloud-backed locations become unresponsive or show errors, and some users saw Outlook fail to open when PST files were stored in services like OneDrive [1]. Microsoft is using an emergency release because the issue is significant enough not to wait for the normal update cadence, and the new patch is cumulative so users only need the latest one installed [1][3].

Primary Source: View original article

Did you know: Microsoft generally uses out-of-band Windows updates only when a serious issue cannot wait for the normal update cycle [1].

Key Points

  • Patch Tuesday fallout: gHacks reports the new out-of-band release (KB5078127) targets serious problems introduced by January 2026’s Patch Tuesday updates [3].
  • Earlier emergency fix: Engadget notes this is the second out-of-band fix tied to January’s security update after issues that left some Windows 11 PCs unable to shut down or hibernate, and caused remote login problems on some Windows 10 and 11 devices [1].
  • Cloud file trigger: Microsoft’s described symptom set centers on cloud-backed file operations, which matters for workplaces that rely on OneDrive-style storage for Outlook data files and other documents [1].
  • One-and-done install: Because the newest out-of-band update is cumulative, it should simplify remediation for IT teams by allowing them to deploy just the latest package rather than multiple hotfixes [1].

Technical Details

  • Out-of-band update: An out-of-band update is an emergency Windows patch released outside Microsoft’s regular cycle when a problem cannot wait for the next scheduled update [1].
  • Cumulative update: A cumulative update bundles prior fixes so installing the newest release brings a system up to date without applying multiple separate patches [1].
  • PST files: A PST is a local Outlook data file; the reported issue includes Outlook crashing or failing to open when PSTs are stored in cloud-based locations like OneDrive [1].

  • Cloud storage workflows: The incident highlights how tightly integrated cloud-backed file locations are with everyday Windows productivity apps, making reliability in sync/storage paths important for both Microsoft and third-party developers [1].

Historical Background

Microsoft regularly ships monthly security fixes on “Patch Tuesday,” and reserves out-of-band updates for issues it deems urgent enough to ship outside that schedule [common][1]. As Windows and Microsoft 365 workflows have shifted toward cloud-backed storage (such as OneDrive), file-access bugs can have outsized impact because many apps depend on the same cloud sync and file APIs [common][1].
