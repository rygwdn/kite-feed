Anthropic to make Claude Code Auto Mode the default on August 14

Category: AI

Anthropic will make Auto Mode the default for new Claude Code sessions on Pro, Max and Team plans starting August 14, Simon Willison reported; Techmeme also summarized the announcement [1][4]. Google News listed items from The Decoder and The Cryptonomist that described the change as part of Anthropic’s work on unsafe approvals and coding-agent safety [2][3]. The change follows Anthropic’s internal use of Auto Mode and evaluations comparing whether the system catches dangerous actions better than users responding to repeated permission prompts [1]. At the AI Engineer World’s Fair, Anthropic’s Cat Wu and Thariq Shihipar said almost everyone inside Anthropic uses Auto Mode, and Wu said the company had largely mitigated risks including prompt injection and data exfiltration [1].

Primary Source: View original article

We’re going to publish some evals in the coming weeks, but we’ve pretty much mitigated every attack. [...] for the main categories of risks that we’re concerned about, like prompt injection and data exfiltration, the risks are far lower than the average human reviewer.

— Cat Wu (Simon Willison’s Weblog)
