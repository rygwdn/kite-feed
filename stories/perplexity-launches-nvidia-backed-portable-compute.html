Perplexity launches Nvidia-backed Portable Computer AI agent

Category: AI

Perplexity launched Portable Computer on Aug. 25, a local-first version of its agentic Computer platform developed with Nvidia that runs on Nvidia DGX Spark desktop systems and Linux machines with Nvidia RTX GPUs [24][5][28]. The company says the model, user files and work can stay on the machine, with every task starting on-device by default and no billing credits used for work completed locally [24][26][31]. Portable Computer can still send an individual step to cloud-based frontier models when a task needs more advanced reasoning, current web information, browser use or connected-app access, but Perplexity says the system asks for permission before doing so [24][25][31]. Perplexity previously expanded from AI search into advertising, personal assistants, browsers and a hosted agent platform [1][5].

Key Points

  • Hardware requirement: Any RTX GPU with at least 24GB of VRAM, about a GeForce RTX 3090 or newer, meets the stated threshold, while Android Authority described the required Nvidia setup as about $5,000 [26][30].
  • Model options: Computerworld reported support for Qwen 3.8 27B or PPLX 27B, a post-trained Qwen variant, while Android Authority said Portable Computer also uses Nvidia Nemotron 3.5 Lightning [31][30].
  • Subscriber rollout: Slashdot reported availability for Pro, Max, Enterprise Pro and Enterprise Max subscribers on Linux, with Windows support planned after the initial release [26].
  • App connections: Portable Computer can connect with Gmail, Outlook, Slack and GitHub, allowing the local agent to work with configured user accounts [27][31].

Technical Details

  • Local orchestration stack: Computerworld reported that the orchestrator, planner, tool router, scheduler, durable task queue and local search index all run on-device. Those components control how the agent plans and executes multi-step work without default cloud processing [31].
  • Multi-agent runtime: Techgenyz reported that the orchestrator LLM, subagent LLM and agent harness stay on the user’s hardware, allowing the system to divide work across agent components instead of only answering a single prompt [29].
  • Cloud escalation path: When local execution is insufficient, Computerworld said the system can escalate to cloud resources for current information, browser use, connected apps or one of more than 15 frontier models [31].

Historical Background

Perplexity first became known as an AI search engine before adding a product called Computer [23]. Computer launched earlier in 2026 as an agentic AI system designed to complete tasks on a user’s behalf [5][23]. Gizmodo reported that the earlier Computer setup used dedicated hardware while the AI processing still depended on the cloud [5].
