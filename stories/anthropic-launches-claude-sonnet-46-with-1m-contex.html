Anthropic launches Claude Sonnet 4.6 with 1M context

Category: AI

Anthropic has released Claude Sonnet 4.6, a new version of its mid-sized “Sonnet” model for everyday developer and knowledge-work use. It’s now broadly available across Claude’s products and the API [3][30][28]. Several outlets describe it as another rapid entry in the current wave of model launches, with Anthropic pitching Sonnet 4.6 as a high-capability option that narrows the gap with the pricier Opus line while keeping Sonnet pricing [2][31][28]. Coverage points to gains in coding, long-context reasoning, and “computer use” tasks—working through real software interfaces—plus an optional extended-context beta mode (with lower default limits) [28][31][2]. Reports also stress how widely available it is across Claude plans, which could bring stronger coding help and document-heavy workflows to more people [28][13].

Did you know: A developer experimenting with Sonnet 4.6-generated SVGs noticed it repeatedly added a “top hat” as a playful detail [31].

Key Points

  • Reliability push: One detailed report says early feedback points to better instruction-following, with less overengineering and fewer hallucinations [28].
  • Benchmarks in the spotlight: A release-focused report says Sonnet 4.6 beats Sonnet 4.5 on agentic/computer-use evaluations, including OSWorld-Verified [28].
  • Knowledge cutoff: Anthropic says Sonnet 4.6 has a “reliable knowledge cutoff” of August 2025, later than the May 2025 cutoff cited for Opus 4.6 in the same materials [31].
  • Cost and pricing: Coverage says Sonnet 4.6 keeps Sonnet’s pricing steady compared with the prior version, while Anthropic continues to position Opus as the higher-priced tier [40].
  • Pricing stays the same: Sonnet 4.6 keeps Sonnet’s published API pricing at $3 per million input tokens and $15 per million output tokens. Opus is priced at $5 and $25 respectively, according to a developer write-up citing Anthropic materials [31].
  • Computer use: Anthropic says Sonnet 4.6 is better at multi-step web tasks—like filling out forms and juggling multiple browser tabs—aiming for more reliable agent-style interaction with computers [35][34][36].
  • Computer-use focus: One release roundup says Sonnet 4.6 is better at navigating real-world software interfaces (like spreadsheets and web forms) without relying on special-purpose APIs [28].
  • Benchmarked progress: Android Headlines points to a “computer use” benchmark rising to 72.5% from 61.4% for the previous Sonnet version [36].
  • Faster daily driver: ZDNET says Anthropic is pitching Sonnet 4.6 as a practical everyday model, and reports it can be faster than Opus 4.6 in many cases [41].
  • Release cadence: TechCrunch notes the launch fits Anthropic’s roughly four-month update cycle for Sonnet [30].

Technical Details

  • Context window modes: Anthropic materials cited by a developer say Sonnet 4.6 and Opus 4.6 default to 200,000 max input tokens, with an optional 1,000,000-token input mode in beta at higher cost [31].
  • Benchmark footprint: A community roundup reports Sonnet 4.6 leading GDPval-AA at ELO 1633, while using substantially more tokens on that evaluation (described as ~4.5x) [29].
  • 1M token context: Sonnet 4.6 includes a 1 million token context window, which allows much larger in-session inputs before truncation [32][34][40].
  • Prompt-injection resistance: A release-focused report says safety evaluations found strong resistance to prompt-injection attacks—an important concern for models that browse or interact with external content [28].
  • Computer-use capability: Coverage links the improvements to more stateful UI interactions across real apps (for example, Anthropic’s claim of human-level performance navigating complex spreadsheets), a key piece for building autonomous or semi-autonomous agents [35][34].

Industry Impact

  • Developer tooling: A community roundup points to integrations and availability across tools and platforms such as Cursor, Windsurf, Microsoft Foundry, and Perplexity tiers—distribution that can speed adoption for developers already working inside those products [29].
  • AI software competition: Forbes reported the Sonnet 4.6 release coincided with declines in some software stocks, suggesting investors saw the new model as adding competitive pressure on software companies that sell AI features [14].

Action Items

  • Pilot computer-use automation carefully: Start with low-risk workflows and keep a human in the loop for multi-step actions, since coverage highlights form-filling and multi-tab browsing as key capabilities [35][34].
  • Re-price your agent workloads: If you use the API, compare projected token spend for Sonnet versus Opus, and shift suitable tasks where quality holds up [40].
  • Try Sonnet 4.6 on long documents: If you use Claude, run Sonnet 4.6 on a large report or codebase to see whether the long-context improvements help. If you have access, compare standard settings with the extended-context beta mode [28].
  • Update Anthropic CLI tooling: If you use Simon Willison’s tooling, update to llm-anthropic 0.24 to access Sonnet 4.6 and Opus 4.6 as described in the release note [31].
  • Try Sonnet 4.6 on the free tier: Go to claude.ai and start a new chat; several outlets say Sonnet 4.6 is now the default for Free and Pro users [33][34][38].
