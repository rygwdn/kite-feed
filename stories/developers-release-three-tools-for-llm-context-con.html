Developers release three tools for LLM context control

Category: AI

Three AI developer projects described tools for context control in large-language-model workflows: TemporalStore presented an open-source, self-hostable memory engine; ThoughtDAG introduced an editable context graph for conversations; and Treequence described a spatial node canvas aimed at LLM context drift [1][2][3]. TemporalStore says its approach moves memory into an engine instead of replaying a growing transcript into every prompt, while ThoughtDAG says the conversation graph determines what enters the next model request [1][2]. Treequence’s submission gave only a brief description, identifying the project as a spatial node canvas built to address context drift [3].

Primary Source: View original article

Key Points

  • Token costs: TemporalStore says repeatedly appending prior prompts, tool results, logs, stack traces and file dumps can make context replay a large part of LLM agent costs [1].
  • Visible context: ThoughtDAG’s demo shows a model request preview with 1,284 tokens and a context diff that removes 47 tokens after an unrelated graph edge is deleted [2].
  • Memory scope: TemporalStore says its stored memory can persist across sessions, devices, agents and teams rather than remain trapped in one transcript [1].
  • Early response: The Treequence Show HN listing showed 4 points and 0 comments when captured in the provided source [3].

Perspectives

TemporalStore: The project says transcript replay is wasteful because old tool output and logs remain in the context window after their immediate usefulness passes.

ThoughtDAG: The project rejects hidden memory selection and says visible graph wiring should show what the model sees, why it sees it and what was removed.
