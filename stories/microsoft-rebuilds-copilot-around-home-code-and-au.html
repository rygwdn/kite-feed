Microsoft rebuilds Copilot around Home, Code and Autopilot

Category: AI

Microsoft announced a redesigned Copilot app that combines Home, Code and Autopilot, bringing chat, delegated work, software creation and persistent agents into one workspace [2][3][5]. Home combines Chat and Cowork with Word, Excel and PowerPoint; Chat handles quick questions and drafts, while Cowork handles longer assignments such as preparing tender responses and financial close packages [2][6]. Code uses GitHub Copilot technology to create tools, while Autopilot is a persistent agent [5][2]. Microsoft plans to route requests among Chat, Cowork and Code based on the task and said edits to documents created in Copilot will sync with Office apps [2].

Primary Source: View original article

Did you know: Microsoft said in July it had more than 30 million Copilot subscriptions, despite fewer than 7% of over 450 million Office 365 business licences including the assistant [7].

Key Points

  • Autopilot’s design draws on OpenClaw; HN.cz said greater agent autonomy raises security concerns and can affect usage costs [4].

Timeline

  • 25 September 2026: Microsoft announced the Copilot redesign and described it as a work OS [2][7].
  • coming weeks: Microsoft plans to begin rolling out Home to Frontier customers [2].
  • September 2026: Microsoft plans to release Code at the end of the month and expand Autopilot to private preview [2].

Technical Details

  • FinOps for AI: The new controls can select a model automatically and require approval for requests for more usage credits [5].

Q&A

Q: When can Microsoft 365 Premium and Pro subscribers try Code?

A: Microsoft said Code will be available to Microsoft 365 Premium and Pro subscribers later in 2026 [5].
