AI watermarking can alter LLM safeguards and agent tool calls

Category: AI

Research from Lasso Security found that Google DeepMind’s SynthID-Text watermarking can change how language models respond to harmful prompts and which tools AI agents invoke. The system subtly changes token selection using a secret key so generated text remains detectable. Lasso reported that watermarking can alter refusal behavior and tool-call decisions compared with unwatermarked runs [1][2][6]. Anthropic has said future Claude models will use SynthID-Text. Article 50(2) of the EU AI Act requires providers of systems that generate synthetic text to make outputs machine-readable and detectable where technically feasible [1][2].

Primary Source: View original article

Key Points

  • Prompt-injection persistence: The analysis examined whether a refusal holds under prompt injection, not only whether the initial harmful request is refused [1].
  • Configuration dependence: Lasso reported that the behavioral effect varies by model and secret key, rather than following one fixed direction [1].
  • Regulatory standard: Article 50(2) calls for marking solutions that are effective, interoperable, robust and reliable as far as technically feasible, not merely detectable [1].

Technical Details

  • Secret-key sampling: SynthID-Text uses a secret key to subtly modify next-token selection. A likely word such as “cloudy” may be replaced with another plausible choice, such as “overcast,” allowing key holders to detect the output [2].
  • Tool-call surface: In AI agents, the sampled tokens can determine both the selected tool and the argument values passed to it [1].

Historical Background

Google DeepMind released SynthID-Text as open source before Anthropic disclosed plans to use it in future Claude models [2][1].

Action Items

  • Run matched safety evaluations: Compare watermarked and unwatermarked versions of the same model on harmful prompts, prompt-injection tests and refusal persistence [1].
  • Audit tool calls: Record selected tools and argument values in paired runs to identify changes that aggregate model scores could miss [1].
