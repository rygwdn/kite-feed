Signal blocks mobile screenshots to keep AI agents from reading chats

Category: Technology

Signal has begun blocking screenshots in its messaging app on iPhones running iOS 27. On supported Android devices, it enables screen protection when it detects an AI assistant trying to read the display. The measures aim to stop assistants such as Apple’s Siri AI and Google’s Gemini Intelligence from capturing private chats [1][14][9]. Users can turn off the protections, but Signal warns that doing so could expose both their own messages and their contacts’ messages to AI systems. The company says the measures are incomplete and that it cannot reliably apply them on macOS [1][18]. Signal President Meredith Whittaker says operating-system agents can capture text after messages are decrypted for display, then make it available to a local database or remote server outside Signal’s control [1][14][7]. The announcement follows a Reuters investigation that found Meta’s Muse agent accessed Signal messages on an Android phone and a Mac using permissions granted during setup, rather than its official Connector tool [14][1]. Meta said Muse accesses other apps only through permissions users explicitly grant [14]. Signal is asking Apple, Google and Microsoft for clear, documented ways for developers to block AI access to their apps’ screens, notifications, files and system APIs, and for technical documentation explaining how agents handle data [1][14]. An Apple system update this week closed the specific Mac access route Reuters identified and added new agent-related permissions and user warnings [14].

Key Points

  • Different controls: On iOS 27, Signal’s “Block Siri AI” setting blocks in-app screenshots by default; on Android, Screen security activates when the app detects an assistant trying to access the screen. Detection works only on some Android versions [1][18].
  • Other access paths: Signal says screenshot controls do not prevent agents from retrieving content already on a device through file-system access or reading messages through notifications [1][8].
  • Access methods: Reuters’ tests found Muse read Signal text from an Android notification; on a Mac, it used accessibility tools and screenshots to capture chats [14][7].

Perspectives

Industry Impact

  • App developers: Signal says Apple and Google are discussing these issues with it [18].
  • Operating-system permissions: Apple’s macOS 27.3 public beta adds more granular controls for Device Control and Data Access and Full Disk Access, along with extra permission prompts; some assistive-technology and backup apps may need Apple’s entitlement [11].

Historical Background

Windows Recall periodically takes screenshots and indexes their contents in a searchable database, which could preserve a copy of a disappearing message after it vanishes from Signal [1][18].

Q&A

Q: What can Mac users do while Signal lacks reliable screenshot blocking there?

A: Signal recommends adding the app to the Excluded Apps list under System Settings > Siri on macOS 27 to limit Siri’s proactive access to message content [18][2].
