Meta launches Muse Code AI coding agent beta

Category: AI

Meta launched Muse Code, a beta terminal-based AI coding agent powered by its Muse Spark 1.2 model, on Wednesday as a direct challenger to Anthropic’s Claude Code and OpenAI’s Codex [21][12][20]. Meta CEO Mark Zuckerberg said the tool can handle software engineering tasks across large repositories, including planning changes, writing code and validating results [12][25][36]. Meta uses AI in its advertising business and is also releasing developer and enterprise tools. Several accounts described coding assistance as one of the generative AI markets with clearer revenue potential, with Microsoft’s GitHub Copilot preceding newer agentic tools such as Claude Code, Codex and Cursor [28][39][27].

Did you know: In one reported stress test, Muse Spark 1.2 made more than 1,000 attempts over 24 hours while looking for improvements to a kernel-optimization task on Nvidia Hopper GPUs [31].

Key Points

  • Benchmark claims: On Meta’s disclosed tests cited by Yonhap, Muse Spark 1.2 scored 82.9% on TerminalBench 2.1, ahead of Codex at 81.8% but behind Claude Code at 86.7% [31].
  • Agent runtime: Muse Code keeps an append-only local event log of model calls, tool runs, approvals and edits, which allows interrupted tasks to resume after crashes [49][36][9][35].
  • Developer access: Muse Code is available for macOS and Linux, installs with a one-line curl command, and currently lacks a dedicated app interface [9][36][49].
  • Enterprise option: Meta said it has started accepting zero-data-retention requests so developer data is not used to improve models, a feature Alexandr Wang called important for enterprise customers [44][17].
  • Pricing tiers: Muse Spark 1.2 costs $1.25 per million input tokens and $4.25 per million output tokens, while the contributor tier costs $0.10 and $0.20 if users allow Meta to use their activity to improve products [21][20][49][14].
  • Access route: Developers can access Muse Code through Meta’s developer site and OpenRouter, with API-key access aimed primarily at software developers and engineers [37].
  • Benchmark results: Zuckerberg posted comparisons showing Muse Spark 1.2 at 82.9% on TerminalBench 2.1, ahead of OpenAI Codex at 81.8% but behind Anthropic Claude Code at 86.7% [31].
  • Agent runtime: The tool uses persistent background subagents and an append-only local event log that records model calls, tool runs, approvals and edits so interrupted work can resume [9][35][49].
  • Enterprise option: Meta has begun accepting zero-data-retention requests so developer data is not used to improve models, a feature Wang described as important for enterprise customers [17][44][31].

Technical Details

  • Co-trained harness: Meta co-trained Muse Spark 1.2 with Muse Code using rejection-sampled harness trajectories, recipe optimizations for goals, compaction and subagents, and the Muse Code toolset to improve harness compatibility [14].
  • Persistent subagents: Muse Code can run background agents that stay active through a session, gather context, take next steps and report back, reducing repeated context collection during multi-stage work [9][37].
  • Main agent loop: The runtime pairs a main agent loop with persistent asynchronous background agents that gather context and decide when to report back, reducing repeated information collection during multi-stage tasks [9].
  • Co-training harness: Meta co-trained Muse Spark 1.2 with Muse Code using rejection-sampled harness trajectories and optimizations for goals, compaction and subagents to improve compatibility with the tool set [14][34].
  • Isolated subagents: For larger jobs, Muse Code can fan work out to subagents operating in isolated worktrees so parallel edits do not touch the user’s working copy [12].

Industry Impact

  • AI coding market: AFP described programming assistance as the main market where AI is generating concrete revenue beyond consumer chatbots such as ChatGPT and Gemini [28][27][39].
  • Competitive pricing: Anthropic’s Sonnet 5 model typically costs $3 per million input tokens and $15 per million output tokens, significantly above Meta’s standard rates [20].
  • Platform competition: The launch puts Meta alongside Microsoft’s GitHub Copilot, Anthropic’s Claude Code, OpenAI’s Codex and Cursor in agentic coding workflows [28][27][39].

Action Items

  • Install only on supported systems: Run the published curl installer from Meta’s developer site on macOS or Linux; you need an API key from Meta Model API or OpenRouter [9][36][49][37].
  • Choose a data tier before testing: Use the Contributor tier only if you accept Meta using prompts, completions or activity to improve products. Choose Standard or request zero-data-retention if code confidentiality matters [49][21][44].
  • Install from Meta’s command line: On macOS or Linux, run the documented command `curl -fsSL https://dev.meta.ai/install.sh | bash` from a terminal [36][9].
