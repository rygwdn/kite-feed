Take-Two removes 3,007 repositories for GTA 6 PC port

Category: Technology

Take-Two Interactive, the parent company of Rockstar Games, used a Digital Millennium Copyright Act notice to take down Project Leonida, an unofficial effort to run Grand Theft Auto VI on PC, across 3,007 GitHub repositories containing its code [1][14]. The company said the project facilitated copyright infringement because it was built to run leaked Xbox game files. It rejected the developers’ instruction for users to “bring your own files” as “intentionally misleading” [1]. The project’s administrator, NotRexed, said its Discord server had also been taken down and ended development [15][5]. The takedown followed the circulation of an Xbox game build and a key executable, which accelerated attempts to recompile the game for Windows and other systems [8][20]. Leonida had reached the game’s setup screen, but footage showed a black screen afterward, not a playable port [25][16]. Other teams are still working on unofficial versions, using AI coding tools to help reverse-engineer the leaked files [2][24]. Rockstar has not announced a PC release date. A report cited by several publications points to the first quarter of 2027, but that timing is unconfirmed [13][24].

Key Points

  • Leonida’s developers estimated it could take about a week to produce a playable build after the leaked executable appeared [16][25].
  • Community shutdowns: Tom’s Hardware reported that Leonida’s Discord server had nearly 180,000 members and that Discord had banned its project account for two years [5].
  • Progress elsewhere: PortWatch VI ranked a group called CGBJ first, drawing on progress from XCL and Victory [8].

Perspectives

Cyberleek, who leaked GTA 6 files, described their release as opposition to what they called anti-consumer practices in the games industry. GameSpot reported, however, that the executable’s release had previously been tied to a cryptocurrency token target [16].

Timeline

  • 19 November 2026: Grand Theft Auto VI launched on PlayStation 5 and Xbox Series consoles [5][11]
  • 20 November 2026: Take-Two said leaked Xbox-build files were publicly distributed [1]
  • 21 November 2026: The Leonida repository opened to run the Xbox build on PC [3]
  • 23 November 2026: Cyberleek released the Xbox build executable, accelerating porting attempts [20][1]
  • 23 November 2026: GitHub processed Take-Two’s takedown across 3,007 repositories [1][14]

Technical Details

  • Static recompilation: This approach translates console code into a native PC version rather than emulating the full console system. Leonida pursued recompilation of the leaked Xbox build [12][2].
  • Emulation: Other groups are attempting to run the Xbox game through an emulation layer on PC rather than recompiling the code to run natively [12][2].
  • Some demonstrations progressed beyond booting: Modders showed a third-person view of Lucia in the prison prologue with shaders rendered, but the game ran at only a few frames per second and had persistent graphical faults [17].

Historical Background

Take-Two had been pursuing the source of the GTA VI leaks for months. In August 2026, it sought subpoenas for data from Discord and Microsoft, which owns GitHub, that could help identify Cyberleek [20].

Action Items

  • Avoid unofficial GTA VI PC installers: Do not download purported working PC builds from unfamiliar sites. Security warnings in the reporting say some fake installers contain malware [12][17].
