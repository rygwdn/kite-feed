Anthropic launches cyber defense program, offers free AI scans for open-source software

Category: AI

Anthropic has launched a cyber defense program for critical infrastructure and a free, opt-in vulnerability scanner for open-source software that uses its AI models to identify security flaws [9][17][20]. The company said the effort addresses the risk that increasingly capable AI can help find vulnerabilities attackers could exploit. The program aims to provide defenders with tools, research and support [4][19]. The OSS Scanner sends AI-generated vulnerability reports directly to participating projects without human review. Anthropic said its models identified more than 29,000 candidate vulnerabilities across core software over the previous six months, but staff had time to manually assess about 6,000 [20]. Anthropic commissioned senior penetration-testing experts to review 97 high- and critical-severity findings across 48 projects. The review found that 85 met the standard for coordinated disclosure. Of the other 12, 11 were real but already known or duplicative, and one was a false positive [20]. Hitachi said Oct. 9 it would join the infrastructure program, whose founding partners include Accenture [19].

Key Points

  • Hospital outreach: Anthropic is inviting hospitals to apply for expanded cybersecurity verification tools [15].
  • Industry partners: Hitachi plans to use Claude and share security knowledge with other participants [19].
  • Scanner improvements: Anthropic says it will refine the system using maintainer feedback and model updates [18][20].
  • Market response: Cybersecurity stocks fell after Anthropic announced the initiative, CNBC reported [16].

Perspectives

Hitachi: The Japanese company says infrastructure operators must rebuild systems on the assumption that attacks will occur [19].

Sources: Sankei Shimbun

Action Items

  • Apply to have an eligible open-source project scanned: A core project maintainer can submit a pull request using the standard project template in the OSS Scanner GitHub repository. Anthropic says it gives priority to projects with a major impact on infrastructure and user safety [20].
