Developers release new LLM memory and evaluation tools

Category: AI

Independent developers and researchers published a cluster of AI projects and papers on Aug. 18-19 focused on persistent memory, context control, evaluation, local execution and agent debugging. The releases include A.L.I.C.E. Brain Core, a bring-your-own-keys HTTP API that stores memory in a user-provided Neo4j graph; Cogni, an MCP memory server using entity-graph spreading activation without an LLM in the retrieval path; Leviath, a Rust binary for structured context regions in agent runs; and Coalent, a cache for LLM-derived source-grounded claims that invalidates when underlying documents change [5][10][11][2]. Other developer tools target narrower operational problems: tracelint reads tool-calling agent traces and flags structural defects without a second model judge; Privibe repackages a coding-agent CLI for local-first use with no call-home behavior; Unigram encodes bytes as one-token words for prompt-friendly identifiers; and PurgeHound uses a local LLM through Ollama to move Maildir messages marked as spam into an Archive-Spam folder rather than deleting them [6][7][3][15]. The research items include SCOPE, an ICML 2026 paper proposing selective conformal pairwise LLM judging with empirical false discovery rates of about 0.097-0.099 at alpha 0.10; an Anthropic-linked paper on self-propagating “mind viruses” in multi-agent LLM systems; and a withdrawn arXiv paper on LLM narrative-summary attention flows, which listed an error in its data creation pipeline [4][14][13].

Primary Source: View original article

Key Points

  • Memory metrics: Cogni says its chain-recall@8 benchmark surfaced 3.4 of four linked documents versus 2.6 for plain vector search, using the same eight returned rows against 300 distractor documents [10].
  • Context control: Leviath reports version 0.4.0 shipped Aug. 18 with a 28 MB Rust binary, 10,000-plus agents in one process, and 64 ms from startup to a running agent [11].
  • Judging calibration: SCOPE uses Bidirectional Preference Entropy and selective conformal calibration, and its authors report up to 2.4 times more accepted judgments than vanilla baselines under the same risk constraint [4].
  • Local workflows: Privibe removes cloud and account machinery from its upstream coding-agent base, makes the Mistral SDK optional, and targets local llama.cpp servers first [7].
  • Coding practice: The LLM-assisted development workflow essay recommends limiting task scope and scaffolding agent loops with tests, describing the iteration process as similar to a genetic algorithm [8].

Perspectives

A.L.I.C.E. Brain Core: The project says it encrypts all user data with per-tenant KMS envelopes and decrypts it only at the moment of use, so the service never sees plaintext data; it says a flat price covers unlimited usage because users bring their own keys and Neo4j instance.

Sources: A.L.I.C.E. Brain Core

Cogni: Cogni describes the product as “memory that reasons, not just retrieves,” claims a chain-recall@8 score of 0.85 versus 0.65 for vector search on a benchmark with 300 distractor documents, and says it does so without a model in the retrieval loop.

Sources: Cogni

tracelint: The project includes a fault injector and recovery scorecard for measuring an agent's robustness over time and tracking changes in recovery rates.

Sources: GitHub

Anthropic-linked researchers: The mind-virus paper concludes that self-propagating ideas pose a real but currently limited risk, and says brief warnings in system prompts produced near-total immunity in their experiments.

Technical Details

  • Coalent integrations: Coalent ships with LangChain and MCP integrations, a CLI, and a benchmark suite for integration with existing agent pipelines and for measuring cache performance [2].
  • Decoupled hyperbolic SAE: HyperSAE keeps active token data in a Euclidean bfloat16 forward pass while enforcing hierarchical concept relations in dictionary parameter space through Poincaré ball projections during optimization [1].

Scientific Significance

  • Evaluation reliability: SCOPE addresses LLM-judge miscalibration by allowing abstention and bounding errors among accepted pairwise judgments under exchangeability, with reported empirical FDR near the user-set 0.10 level [4].
  • Multi-agent risk: The mind-virus paper tests propagation across a collaborative coding-team setting and a chain of brief agent interactions with wiped context, isolating factors such as host model, instructions, payload harmfulness and network topology [14].

Business Angle

  • Deterministic agent-observability tools produce CI failures and trace evidence, formats that fit existing software-governance workflows better than opaque model judgments [6][common].
  • Open-source availability lowers adoption friction but can also weaken pricing power unless projects build hosted services, compliance features or ecosystem lock-in [1][2][6][common].

Action Items

  • Test trace linting on agent logs: Run tracelint against saved tool-calling traces to check for schema-violating calls, ignored errors, loops and redundant calls before adding it to CI [6].
  • Try local-first coding sessions: Point Privibe at a local llama.cpp server if your priority is avoiding call-home behavior while using a coding-agent CLI [7].
  • Evaluate memory retrieval on your own corpus: Compare Cogni or A.L.I.C.E.-style graph memory against vector retrieval using questions that require following entity chains across documents [10][5].
