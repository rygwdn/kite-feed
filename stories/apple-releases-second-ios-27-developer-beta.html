Apple releases second iOS 27 developer beta

Category: Technology

Apple released the second developer beta of iOS 27 on June 22, two weeks after the first beta, which followed the WWDC 2026 keynote. The release came alongside new betas for iPadOS 27, macOS 27 Golden Gate, tvOS 27, visionOS 27 and HomePod Software 27 [5][13][22][49]. The iOS update remains limited to developer testing, with Apple planning a public beta in July and a wider release later this fall or in September [9][24][29]. The new beta adds a more visible Write with Siri control above the keyboard, RCS inline replies and improved reactions for iPhone-to-Android conversations, a Wallet Insights preview for connected account data, and Home app support for installing Apple TV software updates remotely [7][20][9][1][11][21][10][2]. Apple also enabled AirPods Max 2 beta firmware enrollment through iOS 27 or macOS 27 beta 2 and said AirPort Utility will be removed from new App Store downloads, while previously downloaded copies can still be re-downloaded [18][33][64][65].

AirPort Utility will no longer be available for new downloads from the App Store. If you previously downloaded the app, you can still re-download it. When using AirPort Utility on iOS 27 and later, functionality is not guaranteed.

— Apple release notes (9to5Mac)

Key Points

  • Build numbers: The iOS 27 beta 2 build is 24A5370h, while macOS 27 Golden Gate beta 2 is 26A5368g [19][23][49].
  • Recovery tools: iOS 27 introduces an on-device recovery environment with Recovery Assistant, Software Update, Diagnostics Mode, Erase All Content and Settings, and Mac-based Recovery Mode options [16][27].
  • RCS standard: RCS Universal Profile 2.7 supports replies, reactions, custom reactions and sent-message edit, recall and delete capabilities, though iOS 27 beta 2 currently surfaces replies and improved media reactions [44][1].
  • AI dictation: Apple’s advanced AI dictation uses a 20-billion-parameter AFM 3 Core Advanced model and is not enabled by default in the first iOS 27 developer beta [68].
  • Mac interface: macOS 27 Golden Gate beta 2 changes the Liquid Glass interface with opacity controls, shadow changes, uniform toolbars and less rounded app corners [12][23].

Technical Details

  • RCS dependency: RCS reply threading requires both participants to use a smartphone and carrier that support RCS, so iOS support alone does not guarantee the feature will work in every Android-iPhone chat [9].
  • Sparse on-device AI: AFM 3 Core Advanced stores the full dictation model in flash memory rather than DRAM and activates one billion to four billion parameters per request through sparse routing to fit a large model onto supported devices [68].
  • Wallet data path: Wallet Insights’ beta disclosure says account data is fetched, categorized and standardized by an Apple wholly owned subsidiary for display on the device, with account information not stored [11][54].

Industry Impact

  • Cross-platform messaging: Google Messages users will see iPhone RCS replies with the original message included above, while photo reactions now appear as emoji instead of text descriptors [44][9].

Historical Background

Apple added RCS support to iPhone with iOS 18, then expanded cross-platform messaging with RCS encryption in iOS 26.5 before adding RCS replies and richer media reactions in iOS 27 beta 2 [9][44]. Apple discontinued AirPort routers in 2018, and macOS 27 Golden Gate also removes AFP support, ending Time Machine backup compatibility with AirPort Time Capsule devices [64][61].

Action Items

  • Avoid beta on primary devices: Use a secondary iPhone, iPad or Mac and back it up before installing, because early developer betas can bring bugs, battery issues and app compatibility problems [19][53].
  • Check AirPort Utility access: If you still use AirPort Utility, confirm it remains in your purchase history or installed Mac apps before moving to iOS 27 or macOS 27, because new downloads and clean installs are being phased out [64][65].
