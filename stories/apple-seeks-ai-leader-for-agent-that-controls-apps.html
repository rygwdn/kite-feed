Apple seeks AI leader for agent that controls apps, writes code

Category: Technology

Apple is recruiting a senior engineering manager to lead development of an AI agent that could browse the web, operate apps and devices, run commands, and write and debug code for users. The job listing describes a team building agents to plan multistep tasks across apps, browsers, code and application programming interfaces, and to coordinate specialized subagents. Apple has not announced a product or confirmed a release date; Bloomberg reports the project is at an early stage, with a possible launch as soon as late 2027 [13][14][4]. Meta, OpenAI, Anthropic and Google already offer agents that can perform tasks across software or control computers [14][4]. Apple’s listing says privacy and safety must be built into the design, including strong permissions, sandboxing and transparency when agents run code or use account credentials [5][14]. Apple is also adding warnings and approval steps for third-party agents seeking broad Mac access in the macOS 27.3 beta. Enabling ChatGPT’s computer-use tools now takes 14 steps, up from four; Apple presents the controls as security safeguards, while some AI companies and users see them as barriers to competition [12][14].

Did you know: Meta’s Muse exceeded 10 million downloads in the United States within 40 days of launch, according to Sensor Tower figures cited by 9to5Mac [8].

Key Points

  • Access changes: Apple’s October notice to developers said users granting Full Disk Access would face more explicit controls as the company limits what third-party agents can access [11][6].
  • Siri connection: Apple’s job posting says the senior manager would work with teams covering Siri, user-interface frameworks and Apple Foundation Models, but does not confirm whether the agent will be part of Siri [4][12].
  • Rival products: Meta’s Muse can make restaurant reservations and book travel, while Google’s Tasks agent can place phone calls for users [14].
  • Leadership pressure: Bloomberg reported that Apple CEO John Ternus has urged software engineering chief Craig Federighi to accelerate the company’s AI work [14][5].

Perspectives

Mac app developers: Developers of conventional Mac apps have criticized Apple’s expanded warnings, saying even apps that perform simpler tasks require extensive system permissions and macOS lacks sufficiently granular access controls [29].
