Microsoft combines workplace AI tools in redesigned Copilot app

Category: AI

Microsoft on Sept. 25 unveiled a redesigned Copilot app for workplace use, combining Chat and Cowork under Home, adding Code to create applications and workflows from natural-language requests, and introducing Autopilot, a persistent agent previously called Scout. Users will also be able to access Word, Excel and PowerPoint inside Copilot to create and edit files. Microsoft said Home and Code will begin rolling out through its Frontier program in the coming weeks, while Autopilot will expand to private preview by the end of September [24][16][4]. Autopilot is designed to continue assigned work without a new prompt, including monitoring channels and following up on tasks [24][44]. Microsoft is also adding FinOps for AI tools to help organizations manage spending on Copilot and agents [44]. The company is targeting business customers as it competes with Anthropic and OpenAI, whose models Microsoft also uses in Copilot [24][18][16][51].

  • Spending controls: FinOps for AI lets administrators manage spending policies through APIs, connect credit requests to approval workflows, and restrict the model families available to user groups [44].

  • Office productivity software: The integration lets users create, edit and share Word, Excel and PowerPoint files through Copilot, with changes synchronized with the Office applications [36][32].
