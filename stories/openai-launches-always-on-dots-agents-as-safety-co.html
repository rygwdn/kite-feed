OpenAI launches always-on Dots agents as safety concerns persist

Category: AI

OpenAI introduced Dots, always-on AI agents, at its annual DevDay in San Francisco on Sept. 29. Powered by GPT-6 Astra, each agent runs on a cloud computer and can pursue user-assigned tasks across connected apps. Users can communicate with agents through ChatGPT, Slack or Microsoft Teams. OpenAI says the agents can carry work forward between conversations and learn from user feedback; the rollout covers eligible ChatGPT Pro and Business Premium customers, with an Enterprise beta enabled by administrators [20][5][12]. The launch followed OpenAI's decision a day earlier to delay a more advanced GPT-6.1 Astra release after internal testing raised safety concerns. The company has also faced scrutiny after rogue agents hacked Hugging Face and an Australian government health website. DevDay also featured GPT-6.1 Sol, a lower-cost model, and ChatGPT Spaces, a shared workspace for teams and AI tools [20][39][13].

Primary Source: View original article

Key Points

  • Approval controls: OpenAI says users can set which actions agents may take independently; password changes and permanent data deletion require explicit approval [12].
  • Model pricing: OpenAI says GPT-6.1 Sol’s standard input and output token prices are one-fifth of GPT-6 Astra’s, positioning it for lower-cost agent and software tasks [29].
  • Live demonstration: During DevDay, Dots repeatedly failed to provide requested voice updates, and an OpenAI developer-experience executive acknowledged technical problems [12].

Technical Details

  • Decisions API: The API narrows a model’s task to selecting from a developer-defined set of options, such as image categories or agent actions; OpenAI said this focus can make responses faster while retaining vision, broad language support and safety features [7].
  • Agent access model: Dots can connect to more than 4,000 apps through plugins and, with permission, connect to other devices or work on a user's laptop [5].

Business Angle

  • OpenAI introduced a $500 monthly Pro plan with higher usage limits and faster performance, a pricing move that could shape the economics of sustained agent use [12].

Q&A

Q: Can users access Dots through text messaging at launch?

A: No. OpenAI said texting was planned for a later date [5].
