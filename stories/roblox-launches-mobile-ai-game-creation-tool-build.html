Roblox launches mobile AI game creation tool Build

Category: AI

Roblox announced Build, an AI-powered creation feature in its mobile app that lets users turn text prompts into basic playable games without programming experience [2][3][6][7][10]. For example, a prompt for a cozy forest adventure game can generate a starting project that users can playtest, modify, share with friends or publish to Roblox [2][7][10][12]. The feature will enter public alpha testing in New Zealand on July 28 for age-verified users 9 and older, with a broader regional rollout planned in the coming months [8][10][13][15][16]. Roblox said Build uses a mix of open-source and proprietary Roblox AI models and can handle gameplay mechanics, environments, characters, visual style, sound and other development tasks [2][6][7][12].

Primary Source: View original article

Key Points

  • Access limits: Creations that pass Roblox safety checks can be published globally for age-verified users 16 and older [11][13][16][14].
  • Discovery ranking: Roblox said its discovery systems rank games by long-term retention, so AI-generated projects that players do not use should not gain prominent placement [2][10][16].
  • Mobile workflow: Build shares a back end with Roblox Studio, letting creators start projects on phones and continue refining them in desktop Studio with shared models and chat history [8][10][15][11].
  • Discovery rules: Roblox says its discovery system ranks games by long-term retention rather than recency or creation volume, so games that do not attract players will not receive prominent placement [10][2][16][12].
  • Creator tools: Roblox also plans AI agents for professional creators that can playtest for bugs, answer performance questions and suggest changes to improve engagement and retention [7][9][10][16].
  • Usage scale: Roblox reported 132 million daily active users, and MacRumors cited Brookhaven RP, Adopt Me and Dress to Impress among popular user-created experiences on the platform [8][6][11].
  • Mobile-first tab: Build appears as a new creation tab inside the Roblox mobile app, putting game generation directly where users play [10][8].

Technical Details

  • Game-specific model mix: Roblox says Build relies on a broad model set that includes open-source models and proprietary Roblox models trained on 3D models and gaming-specific data [10][2][7][12].
  • Agentic playtesting: Roblox's planned creator agents can run playtests to find bugs, answer natural-language analytics questions and propose changes aimed at engagement and retention [9][7][16].
  • Shared Studio back end: Build and Roblox Studio use shared project infrastructure, models and chat history, so prompts and generated assets can move between mobile Build sessions and the desktop Studio environment [10][15][11].
  • Agentic testing tools: Roblox's planned agents include a playtesting agent for bug discovery, an analytics agent that answers performance questions in natural language and an experiment agent that recommends engagement changes [9][10].
  • Shared Studio back end: Build runs on the same infrastructure as Roblox Studio, so projects, models and chat history can move between mobile Build and desktop Studio workflows [10][15][11].
  • Cube foundation model: Roblox's proprietary Cube model generates game-ready objects that can drive, shoot or otherwise behave as expected without manual scripting, according to The Next Web's account of Roblox's earlier AI tools [10].

Industry Impact

  • Game development labor: TechCrunch reported that developers and players worry text-prompt game creation could increase competition from faster-produced AI-generated content and repetitive games [2].
  • AI game tools: TechCrunch noted that Google, Microsoft and Tencent have built similar AI-powered game-generation tools, placing Roblox's launch within a wider push by large technology companies into prompt-based game creation [2].
  • Creator economy: Build removes the prior desktop requirement for basic Roblox creation by supporting iPhone, iPad and Android workflows in the same app where users play experiences [8][15][16].
  • Mobile platforms: Build expands Roblox creation from Mac and PC workflows to iPhone, iPad and Android devices, changing where Roblox experiences can be started and edited [8][15][16].

Historical Background

Before Build, Roblox creators needed Roblox Studio on a Mac or PC to create experiences, while the mobile app focused on playing and social interaction [8][15]. Roblox introduced agentic Studio tools earlier in 2026, giving the company a model base for generating game-ready 3D objects and behavior [10].

Business Angle

  • Build reduces hardware requirements by letting mobile users create without a Mac or PC [8][15].
  • Roblox said a base version will be free, with additional paid options for power users [7][16].
  • TechCrunch cited surveyed developer backlash toward generative AI, a reputational and creator-relations risk if AI content competes with human-made work [2].

Action Items

  • Check alpha eligibility: Users in New Zealand who are age-verified and at least 9 years old can look for the Build alpha in the Roblox mobile app starting July 28 [10][13].
  • Prepare projects for desktop refinement: Creators who begin in Build can continue work in Roblox Studio because the mobile and desktop tools share back-end infrastructure and chat history [8][15].
  • Review publication requirements: Before publishing, creators should confirm that AI-generated experiences pass Roblox safety checks and meet the age-verification conditions for global availability [11][13][16].
