Apple patches iPhone flaw exposing deleted Signal messages

Category: Technology

Apple released iOS 26.4.2 and matching iPadOS updates to fix a notification-handling flaw that let message previews marked for deletion remain on devices. The patch closes a privacy gap that had allowed the FBI to recover deleted Signal content from an iPhone during forensic extraction [1][4][5][7][8][9]. Apple described the issue as a logging problem, tracked as CVE-2026-28950, in which notifications that should have been removed could instead remain on the device [4][5]. The case drew attention because the recovered material came from Signal, an end-to-end encrypted messaging app whose security model does not protect copies of message text once they appear in operating-system notifications [2][4][9]. Signal welcomed the fix after Apple patched the issue in iOS [4][6].

Primary Source: View original article

Key Points

  • Retention window: Several reports said the affected notification data could remain accessible on an iPhone or iPad for up to a month, extending exposure far beyond a message’s intended lifespan [8][9][6].
  • Physical access: The extraction method required forensic access to the device itself, pointing to a different risk model than remote interception of encrypted chats [2].
  • Signal setting: Signal already offers a setting that hides message text in push notifications, and security commentators said this case shows why some users may want to turn it on [2].

Technical Details

  • Push notification database: The recovered content came from the device’s push notification storage, where incoming message text had been copied outside Signal’s encrypted message store, creating a separate forensic artifact [2][9].
  • Data redaction failure: Apple said the bug was a logging issue fixed with improved data redaction, meaning notification records that should have been scrubbed or deleted were retained locally instead [5].

Industry Impact

  • Secure messaging: The case underscored that encrypted apps can still expose message content through operating-system notifications, pushing privacy-focused services to emphasize notification settings as part of threat protection [2][4].
  • Mobile forensics: The reports showed that forensic tools can recover useful evidence from system-level artifacts even after an app is deleted, a reminder for investigators, security teams, and privacy engineers [2][9].

Historical Background

Signal built its reputation on end-to-end encryption and optional disappearing messages, but those protections do not automatically control how mobile operating systems handle notification previews [common]. Apple has repeatedly framed privacy as a core product feature in recent years [common], which makes this fix notable because it addresses data retention in iOS itself rather than in a third-party messaging app [4][5].

Action Items

  • Install the latest iPhone or iPad update: Update to iOS 26.4.2 or the corresponding iPadOS release to apply Apple’s fix for retained notifications [1][4][5].
  • Hide message text in Signal notifications: Open Signal’s notification settings and disable message-content previews if you want to limit what appears in iOS notifications in the future [2].
