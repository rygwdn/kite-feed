OpenAI, SpaceXAI launch GPT-5.6, GPT-Live and Grok 4.5

Category: AI

OpenAI launched GPT-Live, a new family of voice models for ChatGPT, on July 8, with GPT-Live-1 and GPT-Live-1 mini rolling out globally across iOS, Android and the web [3][23][62]. The models use a full-duplex architecture that lets ChatGPT listen and speak at the same time. OpenAI is replacing the earlier Advanced Voice Mode by default for many users; GPT-Live-1 is the default for Go, Plus and Pro users, while GPT-Live-1 mini is the default for Free users [3][23][56]. OpenAI also said GPT-5.6 Sol, Terra and Luna would launch publicly on July 9 after the company limited access in late June to a small group of vetted partners at Washington's request [36][46][63]. The GPT-5.6 series drew national-security scrutiny because of concerns that advanced AI models could identify software vulnerabilities and accelerate cyberattacks; Sol is OpenAI's flagship model, Terra is a mid-range model for everyday work and Luna is a faster, lower-cost option [36][54][71]. SpaceXAI released Grok 4.5 on July 8 as its latest model for coding, agentic workflows, office tasks and knowledge work, built with Cursor and available through Grok Build, Cursor and the SpaceXAI API console [2][22][53]. SpaceXAI priced Grok 4.5 at $2 per million input tokens and $6 per million output tokens, compared with $5 per million input tokens and $25 per million output tokens for Anthropic's Claude Opus 4.8. Elon Musk described it as comparable to Anthropic's Opus class while emphasizing speed and lower cost [2][41][49].

Key Points

  • Evaluation focus: OpenAI built human evaluations around conversational pleasantness and flow, using 5- to 10-minute one-on-one blind tests that compared GPT-Live with Advanced Voice Mode [42][101].
  • Voice delegation: GPT-Live can hand search, deeper reasoning or complex work to GPT-5.5 while continuing the spoken conversation, and it can return the result when ready [3][23][1].
  • Grok integrations: Grok 4.5 runs as the default model in Grok Build and can operate through CLI, terminal UI, scripts, bots and Agent Client Protocol integrations [22].
  • Account access: Testing Catalog reported that Business, Enterprise and Edu workspaces were not included at launch, even as consumer iOS, Android and web users began receiving the update [22].
  • Usage scale: OpenAI said more than 150 million people each week already use ChatGPT Voice and Dictation [42][101][106].
  • Government boundary: The White House denied giving OpenAI a regulatory “green light,” saying AI model releases remain company decisions even as OpenAI collaborated with Commerce Department officials on testing [10][71].
  • Safety limits: OpenAI added guardrails that can steer the model away from harmful content or terminate higher-risk voice sessions, and some accounts can extend parental controls to teen voice use [87][42][67].

Technical Details

  • Full-duplex voice: GPT-Live continuously processes incoming audio while generating spoken output, allowing it to decide many times per second whether to speak, listen, pause, interrupt or invoke a tool [62][3].
  • Grok 4.5 context and tools: Grok 4.5 supports text and image input, text output, a 500,000-token context window, function calling, structured outputs, web search, X search, code execution and configurable reasoning effort [22].
  • Voice pipeline change: OpenAI's previous ChatGPT voice stack combined speech-to-text, a language model and text-to-speech. The new voice models are designed as native conversational models [3][61].

Industry Impact

  • Customer support automation: Huxiu said OpenAI’s own benchmarks included an internal τ³-Voice Telecom task, suggesting the company tested GPT-Live against multi-turn telecom customer-service scenarios [101].

  • Voice applications: OpenAI said GPT-Live API access is planned soon, giving developers and enterprises a path to embed real-time voice interaction outside ChatGPT [23][62][74].
  • Developer tools: SpaceXAI placed Grok 4.5 directly into Grok Build, Cursor and its API console, and TestingCatalog reported Cursor access on all plans [22][53].
