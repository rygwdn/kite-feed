OpenAI launches GPT-5.3-Codex-Spark for real-time coding

Category: AI

OpenAI has introduced GPT-5.3-Codex-Spark, which it calls its first real-time coding model—meant to make AI-assisted programming feel more responsive and interactive [2]. OpenAI says it can generate up to 15x faster, supports a 128k context window, and launches as text-only. It’s available as a research preview for ChatGPT Pro users and works in Codex (including Codex CLI demos from early access) [2][1]. The release also signals early progress in OpenAI’s partnership with chipmaker Cerebras, announced on January 14. A Codex variant is now showing up that TechCrunch says runs on a dedicated chip [1][3]. Early hands-on notes suggest the big change is speed, not peak output quality—something that could shift how developers iterate by making quick back-and-forth edits and experiments feel effortless [1].

Key Points

  • Model positioning: An independent write-up stresses that Codex-Spark isn’t simply “GPT-5.3-Codex but faster.” OpenAI describes it as “a smaller version of GPT‑5.3‑Codex” [1].
  • What early testing looked like: In Codex CLI, Simon Willison tried a playful prompt—“Generate an SVG of a pelican riding a bicycle”—to show how much lower latency changes the feel of the interaction loop [1].
  • Throughput context: The same write-up cites OpenAI’s ~1,000 tokens/second claim and compares it with a previous Cerebras demo of Llama 3.1 70B at ~2,000 tokens/second (Oct. 2024) [1].
