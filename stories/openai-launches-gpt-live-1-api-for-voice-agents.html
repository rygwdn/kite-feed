OpenAI launches GPT-Live-1 API for voice agents

Category: AI

OpenAI launched GPT-Live-1 in its API on Sept. 10, giving developers access to a real-time voice model that can listen and speak at the same time in AI applications and conversational workflows [1][2][4]. OpenAI said the model is designed for voice agents in business workflows, with support for stronger instruction following, custom voices and telephony use cases [2][1]. Unlike voice systems that link separate speech-recognition, reasoning and speech-synthesis components, GPT-Live-1 processes incoming and outgoing audio together, which OpenAI said avoids latency and handoff problems that can disrupt timing, context and conversational rhythm [1]. Developers can use system prompts to set tone, pace and style, choose backend models and agent harnesses, and connect the voice layer to tools such as GPT-6 Astra, Codex and ChatGPT Work while longer-running reasoning or actions continue [1].

Key Points

  • Developer pricing: TestingCatalog reported that GPT-Live-1 is available in the OpenAI API at $0.05 per minute [1].
  • Voice options: GPT-Live-1 offers 12 voice options [1].
  • Input handling: OpenAI listed ASR transcripts, response text, keyword biasing, alphanumeric recognition and native turn detection among the model’s developer controls [1].

Industry Impact

  • Customer service: OpenAI targeted telephony workflows, including reservations, order updates and customer service, where interruption handling and silence detection affect call quality [1].
  • Language learning: Speak’s reported reduction in interruptions points to an education use case in which users need pauses to formulate spoken responses [1].

Business Angle

  • Usage-priced voice APIs can scale with customer call volume, but latency or turn-taking problems would limit adoption in service workflows [1][common].
  • Competitors can pressure margins if similar full-duplex voice capabilities become commodity features across AI platforms [common].
