OpenAI launches $230 Codex Micro keypad for developers

Category: AI

OpenAI launched Codex Micro, a $230 compact keypad for controlling its Codex AI coding agents, on July 15 in collaboration with Work Louder [1][5][6][8][9][10][11][13][26]. The device is OpenAI’s first branded physical hardware and is aimed at Codex power users rather than general consumers [8][9][11][15]. Codex Micro is a programmable macro pad with mechanical keys, RGB agent-status indicators, a joystick for launching coding workflows, shortcut keys for common Codex actions, and a rotary dial for adjusting the agent’s reasoning level [5][8][10][13][17][26]. Several reports described it as available in clicky and silent versions, with extra Codex icon keycaps for customization [5][11][17][20]. The launch is separate from OpenAI’s rumored Jony Ive-related consumer hardware project, which remains unreleased [10][11][17][26]. OpenAI told TechCrunch the Micro is a limited-run collaboration, while other reports said it is sold through OpenAI’s Supply Co. store and available only until inventory runs out [26][9][6][17].

Did you know: Work Louder previously made a similar collaboration macro pad with Figma in 2023, before partnering with OpenAI on Codex Micro [18][22].

Key Points

  • Thread monitoring: Ars Technica said the top frosted keys can show up to six Codex threads even when they are not in focus on-screen [8].
  • Status colors: The color scheme includes white for idle, blue for thinking, green for complete, amber or orange when input is needed, and red for errors [4][8][5].
  • Workflow shortcuts: The joystick can trigger workflows such as reviewing pull requests, debugging errors and refactoring code [13][17][23].
  • Customization options: The device can be customized through the ChatGPT desktop app and Work Louder software, including remapping keys, joystick functions and dial behavior [4][13][26].
  • Limited availability: Les Numériques reported that early deliveries were estimated for July 24 and that the OpenAI Supply Co. page later showed the product as out of stock [18].

Timeline

Technical Details

  • Dual connection: Reports describe Bluetooth and USB-C connectivity, giving the pad both wireless and wired modes for use beside an existing keyboard [15][20][23].
  • Materials and switches: Les Numériques said the device uses a CNC-machined polycarbonate body, sandblasted anodized aluminum base and POM/POK mechanical switches rated for 50 million keystrokes [18].
  • Remapping flow: TestingCatalog said a long press on the dial inside Codex opens a configuration page where the command keys, dial and joystick can be remapped [4].

Industry Impact

  • Developer peripherals: The launch puts OpenAI’s branding and Codex integration on a hardware category already served by Work Louder’s Creator Micro line and other programmable macro pads [8][15].
  • AI coding tools: CNET said OpenAI reported in April that Codex had more than 3 million weekly users, giving the accessory a defined developer audience even if the hardware run remains limited [9].

Action Items

  • Check availability before buying: Choose the clicky or silent switch version before ordering from OpenAI’s Supply Co. store, if inventory is available [5][9][6].
