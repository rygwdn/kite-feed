Microsoft issues second emergency Windows 11 patch

Category: Technology

Microsoft has released a second out-of-band (emergency) update for Windows 11 in January 2026 after bugs tied to the month’s security update caused problems for some users, particularly in Microsoft Outlook [2][3][1]. The new patch is meant to address crashes and freezes that appeared when Outlook interacted with PST data stored in cloud-backed locations such as OneDrive, and more broadly when some apps opened or saved files in cloud-backed storage [2]. While it’s an unwelcome hiccup, the quick follow-up is a positive sign that Microsoft is prioritizing stability for everyday workflows like email and file access [2][1].

Primary Source: View original article

Did you know: Microsoft Outlook can use local data files (such as PST files) to store mail, calendars, and other items for offline access [common].

Key Points

  • Patch identification: gHacks reports the second emergency Windows 11 fix is rolling out as update KB5078127, issued after January 2026 Patch Tuesday fallout [3].
  • Uninstall guidance: Windows Latest coverage highlighted via Google News says Microsoft advised some users to uninstall Windows 11 update KB5074109 after Outlook POP and PST hangs surfaced following the January 2026 update [1].
  • Why OOB matters: Engadget notes Microsoft typically reserves out-of-band releases for issues serious enough that they can’t wait for the normal update cycle, and says this latest OOB update is cumulative so installing it should cover prior January fixes [2].
  • Earlier January issues: Engadget says a previous January out-of-band update addressed problems including some Windows 11 devices being unable to shut down or hibernate, plus remote-login issues affecting some Windows 10 and Windows 11 systems [2].

Perspectives

Microsoft: Microsoft framed the release as a necessary out-of-band fix for responsiveness and error issues affecting apps that open or save files in cloud-backed locations, including Outlook with cloud-stored PST files [2].

Technical Details

  • Out-of-band update: An out-of-band (OOB) update is an emergency Windows patch released outside the normal schedule to address serious issues quickly [2].
  • Cloud-backed locations: Microsoft said some apps became unresponsive or errored when opening or saving files in cloud-backed storage locations, a key trigger for the reported failures [2].
  • PST files: Engadget reports Outlook could crash or fail to open when PST files were stored in cloud-based options like OneDrive [2].

Industry Impact

  • IT operations: Multiple out-of-band patches in a single month can increase testing and deployment workload for IT teams that manage Windows update rings and change control, especially where Outlook and cloud storage are business-critical [2][common].
  • Cloud productivity: The incident highlights how reliability problems can surface at the intersection of desktop apps and cloud storage, a dependency that affects not just Microsoft but also any vendor building “local app + cloud file” experiences [2][common].
  • Security patching: The situation illustrates the tradeoff organizations face between rapid security patch adoption and operational stability when updates have unexpected side effects, reinforcing the value of phased rollouts and rollback plans [2][common].

Historical Background

Microsoft releases security updates on a regular monthly cadence commonly known as “Patch Tuesday,” and it occasionally ships out-of-band updates when urgent issues emerge between those cycles [common]. The January 2026 Windows security update triggered enough user-impacting problems that Microsoft issued multiple emergency fixes in the same month, underscoring how tightly modern Windows workflows are coupled to cloud storage and enterprise email tooling [2][3].

Q&A

Q: Does the fix address only Outlook, or other apps too?

A: Microsoft said the bug could affect some apps that open or save files in cloud-backed locations, beyond just Outlook [2].

Q: What is a POP account, and why is it mentioned here?

A: POP (Post Office Protocol) is an email retrieval method that downloads messages from a mail server to a device, and Windows Latest reported Outlook POP and PST hangs after the January update [1][common].

Q: Why would cloud storage affect an Outlook data file?

A: Engadget says the crashes appeared when PST files were stored in cloud-based options like OneDrive, suggesting the issue was tied to how Outlook handled data files in cloud-backed locations [2].

Action Items

  • Install the latest cumulative out-of-band update: Use Windows Update to install the newest emergency Windows 11 patch, which Engadget says is cumulative and intended to resolve the January issues [2].
  • Move PST files off cloud sync temporarily if affected: If Outlook crashes or won’t open with PST files in a cloud-backed location like OneDrive, relocate the PST to a local, non-synced folder as a workaround until patched behavior stabilizes [2].
  • Use Microsoft’s uninstall option if you hit the specific bad patch: If you’re impacted and your system received KB5074109, follow Microsoft’s guidance as reported by Windows Latest (via Google News) to uninstall that update [1].
