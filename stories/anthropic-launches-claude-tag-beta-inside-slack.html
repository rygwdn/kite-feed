Anthropic launches Claude Tag beta inside Slack

Category: AI

Anthropic launched Claude Tag, a beta feature that places its Claude AI agent inside Slack channels for Claude Enterprise and Claude Team customers [7][20][22][26]. Employees can summon the agent by typing “@Claude” in a Slack thread, where it can read authorized conversations, break down tasks, retain channel context over time and return work in the same discussion [7][22][23][29]. Anthropic said Claude Tag is available in beta, with plans to expand the experience beyond Slack [22][26].

Primary Source: View original article

Key Points

  • Admin controls: Administrators can set channel-specific access, review logs and impose spend limits, including monthly token and cost caps described in enterprise rollout coverage [20][28][29].
  • Ambient mode: When enabled, Claude Tag can surface relevant information from other channels and connected tools, follow up on unresolved discussions and notify teams without a direct tag [23][29].
  • Internal use: Anthropic said its product team has used Claude Tag internally for product metrics, support work, bug investigation and code generation, with one source citing 65% of product code created through Slack tagging [25][29].
  • Enterprise demand: Ramp’s May 2026 AI Index showed Anthropic leading OpenAI in enterprise adoption, according to Artificial Intelligence News [7].

Slack: Rob Seaman, Slack’s general manager, described the integration as “making AI multiplayer,” emphasizing that Claude Tag works in shared channels rather than private chats.

Technical Details

  • Agent identity: Claude Tag assigns Claude its own workspace or channel identity with separate permissions, so access can be revoked by disabling that identity rather than untangling privileges across employee accounts [28].
  • Compartmental access: Admins can give one channel’s Claude access to tools such as GitHub and a data warehouse while limiting a CRM connection to a private sales channel, keeping permissions scoped by workspace context [28].
  • Asynchronous execution: Claude Tag can schedule follow-up work for itself and continue tasks over hours or days, then return progress and results inside the Slack thread [23][29].

Industry Impact

  • Enterprise security: Help Net Security reported that Claude Tag’s separate agent identity can reduce exposure of private documents by avoiding reliance on individual user credentials in shared channels [28].
  • AI competition: Anthropic’s post-money valuation reached $965 billion after a $65 billion Series H round, surpassing OpenAI’s $852 billion [7].

Historical Background

Slack became part of Salesforce after Salesforce completed its $27.7 billion acquisition in 2021 [common]. Anthropic previously offered Claude in Slack, but CIO reported that the older version only interacted with one person at a time and used a much smaller channel context window than Claude Tag [23].

Business Angle

  • Claude Tag works in shared Slack channels and can retain channel context over time, moving Anthropic’s agent from one-on-one chats into project discussions [7][23].
  • Ramp’s May 2026 AI Index reported Anthropic at a 34.4% enterprise adoption rate; whether that leads to durable paid usage remains unclear [7][common].
  • The feature also gives Salesforce’s Slack another AI tool inside the collaboration platform [22][common].

Action Items

  • Audit Claude Tag permissions before rollout: Map each Slack channel to the repositories, tools, API keys and data sources Claude should access, then use admin controls to limit access by channel [28][20].
  • Set a spending ceiling: Configure monthly token or cost limits at the organization or channel level before wider testing [20][29].
  • Test in private channels first: Sapo reported that administrators have a 30-day transition period and launch credits for internal testing, making a limited pilot the safest first step [26].
