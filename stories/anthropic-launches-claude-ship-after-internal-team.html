Anthropic launches Claude Ship after internal team reports doubled merges

Category: AI

Anthropic launched Claude Ship on Nov. 23, extending its Claude AI tools to code review, fixes and policy-based approvals in GitHub repositories for Claude Team and Enterprise customers [13][8]. Anthropic cited results from its own Claude Code team: merged pull requests more than doubled from June to September 2026, while the share later reverted fell by more than 40% [7][10]. Anthropic cautioned that Claude’s review was only one layer in a broader process, so the internal figures do not isolate Claude Ship’s effect [10]. Anthropic said developers using agents generate code faster than teams can review and approve it [8][29]. Anthropic bills for token consumption, with costs varying by pull-request volume, size, review depth and automated fixes [7]. The company recommends testing approval policies in observe-only mode before requiring them for merges; its documentation also warns that automated review can miss bugs and security vulnerabilities [7]. The policy-based approval tool Claude Approvals and PR Steward, which helps contributors address review findings, remain in beta, while Code Review is generally available [8].

Key Points

  • Internal workflow: Anthropic described a Claude Code workflow in which a product manager used its Claude Tag agent to turn customer feedback into a pull request, with documentation and approval completed that night [29].
  • Billing mechanics: Claude Approvals has no base fee, but its policy classifiers use billable tokens, and a policy-triggered Code Review can incur charges even in observe-only mode [7].
  • Restricted access: Organizations using Zero Data Retention, HIPAA settings or customer-managed encryption keys cannot use Claude Ship [6][2].
  • Enterprise credits: Eligible Enterprise organizations can claim at least $10,000 in Claude Ship credits by Jan. 15, 2027. The credits are usable for 30 days after claiming [4][7].

Perspectives

TELUS Digital: Engineering director Vatsal Bhatt said Code Review has repeatedly found genuine issues before human reviewers saw a pull request, while PR Steward helps contributors address them; he said human review remains in place [29].

Technical Details

  • Policy-file enforcement: Claude Approvals reads a repository policy file. If teams set rules carelessly, text supplied by the pull-request author may influence a classifier, potentially lowering the required approval threshold [29].
  • Merge safeguards: A passing Claude Approvals check does not guarantee human review. If GitHub does not require the check or policy rules require no human approval, auto-merge or a merge queue can merge the change without a person acting [7][29].
