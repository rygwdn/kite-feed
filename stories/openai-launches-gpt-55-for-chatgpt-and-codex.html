OpenAI launches GPT-5.5 for ChatGPT and Codex

Category: AI

OpenAI introduced GPT-5.5 on April 23, calling it its smartest model yet and aiming it at coding, research, data analysis, and broader agent-style computer work across tools [17][1][8]. The company rolled it out immediately in ChatGPT and Codex for paid tiers, while saying API access would come later because serving the model through the API needs additional safety and security safeguards at scale [17][3][13][20]. Across coverage from OpenAI, mainstream outlets, and early testers, the clearest theme was not just raw capability but a push toward more autonomous, longer-running work. OpenAI said GPT-5.5 does a better job of understanding complex goals, using tools, checking its work, and carrying tasks through to completion, while TechCrunch and Latent Space framed the launch as part of a broader strategy to make ChatGPT and Codex more central to everyday software use [17][1][7]. Early reactions were generally positive, especially around coding and long-horizon tasks, though several reports also said some gains look incremental on benchmarks and that hallucinations and safety concerns have not gone away [3][12][13][8].

Key Points

  • Pricing: OpenAI set GPT-5.5 at $5 per 1 million input tokens and $30 per 1 million output tokens, while GPT-5.5 Pro costs $30 and $180 respectively, roughly double GPT-5.4 pricing according to Smol AI's roundup [3].
  • Early uptake: Third-party support appeared quickly after launch, with Smol AI noting Hermes Agent integration and Simon Willison documenting early access through a semi-official Codex-related route rather than the standard public API [3][20].
  • Benchmarks: OpenAI's published comparisons cited scores of 82.7% on Terminal-Bench 2.0, 58.6% on SWE-Bench Pro, and 78.7% on OSWorld-Verified, with TestingCatalog reporting GPT-5.5 ahead of Claude Opus 4.7 and Gemini 3.1 Pro on Terminal-Bench 2.0 [13][17].
  • Benchmark lead: OpenAI said GPT-5.5 scored 82.7% on Terminal-Bench 2.0, ahead of GPT-5.4 at 75.1%, Anthropic Opus 4.7 at 69.4%, and Google Gemini 3.1 Pro at 68.5% [27].
  • Codex upgrades: The launch also brought browser control and OS-wide dictation to Codex, along with broader workflow changes that commentators framed as part of OpenAI's push beyond coding help alone [3][7][1].
  • Computer control: On OSWorld-Verified, GPT-5.5 scored 78.7%, versus 75% for GPT-5.4 and 78% for Anthropic’s Opus 4.7, suggesting modest but measurable gains in operating a computer independently [27].
  • Access plan: OpenAI is rolling GPT-5.5 out to Plus, Pro, Business, and Enterprise ChatGPT users, while GPT-5.5 Pro is limited to Pro, Business, and Enterprise tiers [26].

Technical Details

  • Terminal-Bench 2.0: This benchmark measures complex terminal workflows that require planning, iteration, and tool coordination; OpenAI reported GPT-5.5 at 82.7%, a sizable jump from GPT-5.4’s 75.1% [27].
  • Subscription access path: Simon Willison noted that some developers evaluated GPT-5.5 through a Codex-specific backend endpoint tied to paid subscriptions instead of the standard API, highlighting the growing technical distinction between chat products, agent shells, and raw model endpoints [20].
  • Per-token latency: The Next Web reported that GPT-5.5 matches GPT-5.4’s per-token latency, meaning OpenAI says it improved capability without slowing down each generated token [23].
  • Agent harnessing: The model is tuned for longer multi-step execution with tool use and self-checking, so performance depends not only on the base model but also on the surrounding agent loop that can call tools, inspect intermediate results, and revise outputs before returning an answer [17][3].
  • Token efficiency: Multiple reports said GPT-5.5 often uses materially fewer output tokens than GPT-5.4 on comparable Codex tasks while keeping similar per-token speed, which matters because total task cost depends on both token price and token consumption [3][13].
  • OSWorld-Verified: This test evaluates whether a model can operate a computer independently, making it a more direct measure of agent-like desktop use than text generation alone [27].

Industry Impact

  • Agent tooling: Fast third-party integration, including Hermes Agent support noted by Smol AI, shows how quickly agent frameworks now adapt to new frontier models once access appears [3].
  • Enterprise software: OpenAI is positioning GPT-5.5 for spreadsheets, documents, research, and cross-tool workflows, signaling stronger competition for workplace software use cases [26][28].
  • Developer tools: OpenAI said GPT-5.5 will power a stronger Codex agent, and its large weekly developer base suggests continued pressure on coding-assistant vendors to improve autonomous software tasks [27].
  • AI rivalry: The release intensifies competition with Anthropic and Google, with benchmark comparisons across Terminal-Bench 2.0 and OSWorld-Verified helping frame the race for leadership [27][25].
  • Developer platforms: API customers must wait for GPT-5.5 and GPT-5.5 Pro while OpenAI completes additional safeguards, creating a temporary split between users of hosted products and developers building direct integrations [17][3][20].
  • Enterprise software: OpenAI targeted paid ChatGPT tiers including Plus, Pro, Business, and Enterprise, suggesting the company sees immediate commercial demand in workplace productivity and developer tooling, not just consumer chat [17][13].
  • Model pricing: Reported pricing for GPT-5.5, and especially GPT-5.5 Pro, keeps pressure on rivals to compete on both capability and intelligence-per-dollar, a metric highlighted repeatedly in ecosystem commentary [3][7].

Scientific Significance

  • Research assistance: Several reports say OpenAI tuned GPT-5.5 to perform better on math, science, and broader research tasks, signaling that frontier models are moving beyond chat into hypothesis generation, literature work, and tool-driven investigation [22][27].
  • Evaluation shift: The launch shows how AI progress is increasingly judged on action-oriented benchmarks such as terminal workflows and computer operation, not just static question-answer tests [27].
  • Limitations: Independent validation remains limited in the provided coverage, and OpenAI’s decision to delay API access for added safety work suggests capability claims are still being weighed against deployment risk [23].

Historical Background

OpenAI launched ChatGPT in late 2022, helping spark the current wave of consumer and enterprise interest in generative AI [common]. Since then, competition among frontier-model developers such as OpenAI, Anthropic, and Google has shifted from chatbot quality alone toward coding ability, tool use, and agentic task completion, which several of these articles use as the backdrop for GPT-5.5's release [7][13][8]. OpenAI has also been expanding Codex-related tooling, which helps explain why this launch paired a model update with product changes instead of treating it as just another benchmark release [20][7].
