Anthropic links Claude memory between chat and Cowork

Category: Technology

Anthropic said on Tuesday that Claude chat and Claude Cowork now use the same memory system, allowing context to move in both directions between standard chats and Cowork tasks [1][2][3][8][10]. Cowork can use details from prior Claude conversations when it runs cloud tasks, while information saved in Cowork can later appear in chat [1][6][7][9]. The company also changed how Claude stores memory: it can add topics while a conversation is still happening instead of waiting until the chat ends, and users can view saved memories by topic and read, edit, delete, pause or reset them in settings [2][3][8][9]. Anthropic said memory is on by default for Free, Pro and Max plans across web, desktop and mobile, while sensitive topics such as health, race, ethnicity, religious beliefs, politics and gender identity remain excluded unless users enable a separate setting [5][7][11][13].

Primary Source: View original article

Cowork now has memory, and it’s the same one you use in chat, leading to less re-explaining and more picking up where you left off.

— Anthropic (9to5Mac)

Key Points

  • Plan support: The shared memory feature applies to Free, Pro and Max users, while Team and Enterprise availability depends on administrator settings. Individual users are off by default in those work plans [5][13].
  • Chrome context: Engadget linked the update to Anthropic’s recent Claude for Chrome change, which made Cowork available through the browser extension and added side-panel conversations to a user’s usage history [1].
  • Coding exception: ZDNET said Anthropic did not include Claude Code in the announcement, and The Register reported that Claude Code remains separate from the shared chat-Cowork memory system [6][10].
  • Privacy tradeoff: ZDNET described the merged memory system as a productivity improvement that also raises privacy questions about what AI assistants retain and whether users accept that exchange [6].

Perspectives

Anthropic: The company framed the change as a way to reduce repeated explanations when users move from planning in chat to assigning tasks in Cowork.

Sources: Engadget

ZDNET: David Gewirtz wrote that the update creates a serious privacy tradeoff because Anthropic is letting more Claude surfaces share personal context by default.

Sources: ZDNET

The Register: The publication reported that users cannot keep separate memories for chat and Cowork, while Claude Code stays outside the combined system.

Sources: The Register

Industry Impact

  • Agent workflows: TechCrunch said the change lets users move from research in chat to action in Cowork without re-entering project details [8].
  • Consumer AI privacy: The Next Web noted that real-time memory capture removes the previous end-of-chat moment when a user might have decided an exchange was not worth keeping [7].

Historical Background

Claude already had memory before this release, but Engadget reported that those memories had often been fragmented because of design choices and limits in Claude’s architecture [1].

Action Items

  • Review Claude memories: Open Settings > Memory to inspect saved topic files, then edit or delete entries you do not want Claude to reuse [3][9].
  • Check sensitive-topic settings: Keep sensitive-topic memory off unless you explicitly want Claude to retain information such as health, beliefs, politics or gender identity [5][8].
  • Update mobile apps: Install the latest Claude app on iOS or Android to get the current memory controls and behavior [5].
