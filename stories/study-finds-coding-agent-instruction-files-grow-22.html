Study finds coding-agent instruction files grow 226% over time

Category: AI

A new study of AI coding-agent instructions found that files such as CLAUDE.md grew by 226% over their lifetimes as additions outpaced deletions across 1,867 repositories. Researcher Kushal Chakrabarti analyzed 247,694 instruction lifetimes and attributed the pattern to agents’ imperfect recall of why older instructions were added [6]. The paper, revised Nov. 20, reports that comments recording the reasoning behind instructions cut excess prompt size by 99.3% in constructed tests. In small-scale tests in real repositories, the approach also improved instruction-following by 17.7% [6]. The coding agent Claude Code is also being used for projects beyond conventional software development, including hobbyist-built apps and hardware prototypes [2][7]. A separate review of the free coding agent Freebuff warns that it logs mouse and keyboard input and may use submitted information for advertising and AI training [5].

Primary Source: View original article

If English is the new code, why don't we have comments yet?

— Kushal Chakrabarti (arXiv)

Key Points

  • Prompt drift: The paper measured a net increase of 4.7 instructions per commit and found that the chance of deleting an instruction falls geometrically as it ages [6].
  • Tuning workflow: Sybil Solutions’ open-source skill benchmarks local-model serving using interleaved control runs, a memory cap and long-context checks. ExplainX says it did not independently rerun the published performance figures [3].
  • Prototype hardware: One Claude Code project used an ESP32-C3, motion sensor and OLED display in an hourglass prototype that controls iPhone app access. Its planned 211-LED circuit board still needs to be manufactured and tested [7].
  • Paid access: Claude Code is not included in Anthropic’s free subscription, and Tom’s Guide lists Claude Pro at $20 a month as the starting paid plan [2].

Perspectives

Notebookcheck reviewer: The review argues that Freebuff collects more data than is common among ChatGPT-like services, citing interest profiles derived from user input and the collection of device information [5].

Sources: Notebookcheck

Technical Details

  • Deletion-cost model: The paper says that once the reasoning behind an instruction is lost, deciding whether it can safely be removed can require O(2^|D|) work in a prompt containing |D| instructions [6].
  • Comparison with context maintainers: The paper reports that comment-based prompts were smaller than those produced by existing context-maintenance approaches in real-world and coding-convention settings [6].

Scientific Significance

  • Failure risk: The paper warns that instruction accumulation may continue until agents become nonfunctional; it says growth otherwise stops only when project history ends or someone rewrites the file wholesale [6].

Q&A

Q: How stable is Freebuff’s free access?

A: The review says available models and free-use limits can change and vary by country. It reports that DeepSeek V4.1 Flash Fast was limited to three hours and that larger models were increasingly tied to paid plans [5].
