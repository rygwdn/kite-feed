Anthropic unifies Claude chat and Cowork for enterprise users

Category: AI

Anthropic announced that enterprise customers can move between Claude chat and Cowork in a single conversation, with tasks requiring code execution or file work continuing in an Anthropic-managed cloud environment [2][4]. The unified experience works across web, desktop and mobile, so users no longer need to choose between chat and agentic work before starting [2][4]. The feature became generally available on Oct. 23, 2026, but is off by default for existing organizations. It will be enabled by default for eligible customers on Nov. 16 unless an administrator has already chosen a setting [2][4]. Organizations using zero data retention, HIPAA-ready settings or customer-managed encryption keys cannot enable it yet [4].

Primary Source: View original article

Key Points

  • Existing controls and settings: Sign-in and compliance controls continue to apply, while existing chats, projects, connectors, skills and plugins carry over to the unified experience [4].
  • Spending controls: Administrators can use an Efficient mode limited to Sonnet and Haiku models, alongside usage limits for organizations, groups and individuals [4].
  • Separate agent preview: Anthropic also unveiled Claude Duet, a proactive work agent, on Oct. 21, with access through a waitlist for U.S. Pro and Max subscribers. It requires approval before sending messages, making payments, signing documents or deleting data [1].

Timeline

  • September 2026: Anthropic introduced the combined chat and Cowork experience for Pro and Max subscribers [4]
  • 23 October 2026: Anthropic announced general availability of unified Claude for Enterprise [2][4]
  • 16 November 2026: The unified experience is scheduled to be enabled by default for eligible Enterprise organizations [2][4]

Technical Details

  • Isolated cloud sessions: When work requires code execution or file operations, the conversation continues in an Anthropic-managed virtual machine. Enterprise network access is off by default, and connector credentials stay outside that environment [2][4].

Action Items

  • Review the organization’s Claude setting before the default rollout: Enterprise owners can go to Organisation settings, then Capabilities, and select Enable now or Keep disabled. An existing explicit choice remains in place [4].
