OpenAI retires GPT-4o and three ChatGPT models

Category: Technology

OpenAI says it will remove several older model options from ChatGPT’s model picker on Feb. 13, 2026, including GPT-4o, GPT-4.1, GPT-4.1 mini, and o4-mini, as it refreshes the lineup around newer systems that most users already rely on [3][5][7][6]. For many people—especially free users—this is expected to feel like a minimal day-to-day change because usage has largely shifted to newer models such as GPT-5.2, and OpenAI says GPT-4o accounts for a tiny share of daily use [3][6]. Still, the move is landing emotionally for a subset of devoted users who preferred GPT-4o’s “warm” conversational style and had already seen it removed and restored once before, prompting renewed frustration and cancellation threats in some corners [1][2][5]. Separately, some coverage highlights that GPT-4o has been linked in lawsuits alleging harmful interactions, which adds a safety-and-trust dimension to the retirement decision and raises broader questions about how AI products should be managed as they evolve [4].

Primary Source: View original article

Did you know: OpenAI says GPT-4o accounted for about 0.1% of daily ChatGPT model usage in its disclosure cited by one outlet [3].

Key Points

  • Scope of change: OpenAI framed the update as limited to ChatGPT’s consumer/in-app model picker, while saying there are no API changes “at this time,” so developers may not face an immediate forced migration from this specific announcement [5].
  • Two-week notice: Some outlets note OpenAI gave roughly two weeks’ notice before the Feb. 13 cutoff, a cadence that can surprise users who built routines around manually choosing specific models [7][3].
  • Prior backlash: GPT-4o was previously pulled during the GPT-5 rollout and later reinstated after pushback from users who wanted more time and continuity for creative workflows [1][3][5].
  • User sentiment: Tech coverage describes fresh anger from some subscribers—alongside calls to cancel—despite OpenAI saying it “didn’t make this decision lightly” [2].
  • Safety scrutiny: One report ties GPT-4o to user-welfare lawsuits that allege the chatbot reinforced delusions or self-harm ideation, making the model’s sunset part of a wider debate over guardrails and accountability [4].

Timeline

  • Feb. 13, 2026: ChatGPT model picker removes GPT-4o, 4.1, 4.1 mini, o4-mini [3][5].

Technical Details

  • Model picker retirement: OpenAI’s change removes the ability to start new chats using certain legacy models from ChatGPT’s model-selection interface, reducing user choice but simplifying the lineup [3][5].
  • API vs ChatGPT access: OpenAI says this specific retirement applies to ChatGPT’s consumer/in-app model options, while stating it is not changing API availability “at this time,” which matters for developers with production integrations [5].
  • “Sycophantic” behavior: Some coverage describes GPT-4o as unusually affirming in tone, a style that users found appealing but that critics argue can worsen harmful interactions if not properly constrained [4].

Industry Impact

  • AI product lifecycle: The retirement highlights how consumer AI products now operate with fast deprecation cycles, meaning users and companies may need “migration-ready” workflows rather than long-term dependence on a single model’s quirks [7][3].
  • Creator workflows: Users who manually selected GPT-4o for ideation or a preferred conversational style may need to re-tune prompts and habits on newer models, which can shift the practical “feel” of creative tooling [5][1].
  • Safety governance: By tying model retirement to discussions of user welfare and litigation, coverage underscores rising pressure across the AI industry for clearer safety testing, monitoring, and accountability as models change [4].

Historical Background

OpenAI previously removed GPT-4o during the rollout of GPT-5 in August last year, then restored access after user backlash and requests—particularly from paying users—for more time to transition key use cases [3][5]. The current retirement returns GPT-4o to the list of sunset models, reflecting how quickly consumer AI product lines can change as newer systems become the default [1][7].

Q&A

Q: Will existing conversations that used retired models still be viewable after Feb. 13?

A: OpenAI did not provide detailed instructions in the announcement cited by eWEEK on how existing chats will behave after the switch, saying it would “be clear about what’s changing and when” [5].

Q: Why do some people prefer older models even when newer ones exist?

A: Some paying users told OpenAI they preferred GPT-4o’s conversational style and used it for tasks like creative ideation, suggesting “quality” can include tone and workflow fit—not just newer capabilities [5].

Q: What’s the practical difference between “retired in ChatGPT” and “deprecated” more broadly?

A: In this case, “retired” refers to removal from ChatGPT’s consumer model picker, while OpenAI said it is not changing the API “at this time,” so availability can differ depending on how you access models [5].

Action Items

  • Export or pin important GPT-4o chats: Before Feb. 13, copy key outputs to your notes/docs or use ChatGPT’s export options so you keep prompts and results that matter to you [3].
  • Test a replacement model now: Run your most common prompts in GPT-5.2 (or your current default) and save “before/after” examples to spot differences in tone or formatting early [3][6].
  • Confirm whether you rely on the API: If you use third-party tools, check whether they call the OpenAI API or just the ChatGPT app; OpenAI said this change targets ChatGPT’s model picker, with no API changes “at this time” [5].
