Anthropic cuts Haiku 5.5 API costs, adds agent tools

Category: AI

Anthropic released Claude Haiku 5.5 on Oct. 7, charging $0.10 per million input tokens and $0.50 per million output tokens for requests of up to 100,000 tokens; longer requests cost five times as much. Anthropic says the model’s average running cost is about 75% lower than Haiku 4.5’s, while the lower tier is 90% cheaper per token. Haiku 5.5 is aimed at high-volume tasks such as summarization, classification, database queries and customer support [7][40][53]. The model introduces adjustable effort settings to the Haiku line and is designed to handle repetitive tasks or serve as a subagent alongside larger Claude models. In tests reported by Anthropic, it scored 72.4% on OSWorld 2.1, compared with 15.7% for Haiku 4.5, and 39.2% on Terminal-Bench 4.0, compared with zero for its predecessor. Anthropic still recommends Sonnet 5.5 and Opus 5.5 for complex coding [7][40]. Alongside the launch, Anthropic halved Sonnet 5.5 cache-read prices and began adding monthly API credits for Max and Team subscribers. Haiku 5.5 is available through the Claude Platform and major cloud providers, with beta support for browser and computer use in Anthropic’s Python and TypeScript SDKs [7][44].

Key Points

  • Customer tests: Asana reported more than 30% lower latency and up to 2.5 times faster inference per agent turn; Box said Haiku 5.5 scored 11 points higher than Haiku 4.5 at about half the latency [40].
  • Tokenizer trade-off: In Simon Willison’s test, the revised tokenizer used about 1.25 times as many tokens for the same long prompt, potentially reducing savings for some workloads [2].
  • Long prompts: For prompts between 100,000 and 272,000 tokens, GPT-6 Luna remains in its lower pricing tier while Haiku 5.5 has crossed into its higher tier, making Luna cheaper in that range [2][47].
  • Safety limits: Anthropic permits more defensive cybersecurity work with Haiku 5.5 than with Sonnet 5.5 but continues to block penetration testing. Its biology safeguards match those on its Sonnet and Opus models [41][40].
  • Subscriber credits: Max 5x users receive $100 in monthly API credits, Max 20x users receive $200, and Team subscribers receive up to $500 pooled across users; unused credits do not roll over [7][2].

Technical Details

  • Prompt caching: For requests in the lower pricing tier, Haiku 5.5 cache reads cost $0.01 per million tokens and cache writes cost $0.125 per million tokens [7].
  • Effort controls: The effort setting defaults to medium; Haiku 5.5 has no option to disable reasoning [2].
  • Benchmark scope: OSWorld 2.1 measures computer-use capability, and Terminal-Bench 4.0 tests command-line tasks. Anthropic reported the cited Haiku scores; Sonnet 5.5 scored 83.9% and 70.6% on those tests, respectively [40].

Business Angle

  • Anthropic’s monthly API credits are available to Max and Team subscribers; unused credits expire each month and do not roll over [7][2].
  • Haiku 5.5 matches GPT-6 Luna’s prices for routine, high-volume inference workloads [2][47].

Q&A

Q: Can developers use Haiku 5.5 for browser and computer-control applications?

A: Yes. The beta toolsets require developers to provide their own browser or desktop drivers [7].

Action Items
