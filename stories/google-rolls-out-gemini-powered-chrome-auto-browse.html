Google rolls out Gemini-powered Chrome auto browse tool

Category: AI

Google is rolling out a new opt-in “Auto Browse” feature in Chrome that lets its Gemini AI act like an online agent, taking on multi-step web tasks such as shopping, trip planning, and making appointments for the user [1][2][3]. The feature is available first to a limited set of paid AI Pro and Ultra subscribers in the US on macOS, Windows, and Chromebook Plus devices, positioning Chrome as an assistant rather than just a browser [3][1]. In early hands-on use, the promise is clear—delegating tedious web errands—yet the experience can still feel rough around the edges, with WIRED reporting that the agent didn’t consistently “click” in practice [2]. Google says the system is designed to keep users in control, with explicit opt-in, app-connection controls, and the ability to disconnect at any time, while also remembering past topics for more tailored help [3].

Did you know: TestingCatalog says Chrome Auto Browse goes beyond autofill by handling multi-step processes like scheduling, financial tasks, and shopping [3].

Key Points

  • Model upgrade: TestingCatalog reports Auto Browse is built on Gemini 3 and uses multimodal capabilities, including interpreting images to help find products during tasks [3].
  • Deeper permissions: The feature can manage sign-ins and assist with transactions when the user permits it, extending beyond traditional autofill behavior in Chrome [3].
  • Task range: Google’s rollout materials and early reports describe the agent helping with errands like renewing licenses, collecting tax documents, and getting service quotes—examples aimed at time savings rather than novelty [3].
  • Real-world friction: WIRED’s hands-on testing notes that while Auto Browse aims to handle actions like buying tickets and shopping, execution and reliability did not always meet expectations [2].
  • Subscriber gating: PCMag says access is currently tied to paid Google AI subscriptions, framing Auto Browse as a premium productivity add-on rather than a default Chrome feature [1].

  • Multimodal input: TestingCatalog says the feature leverages Gemini 3’s multimodal capabilities, including interpreting images while searching for products [3].
  • Opt-in permissions: The rollout is opt-in with user controls over what apps can connect, and it can handle sign-ins and transactions when permission is granted [3].

Industry Impact

  • Browser competition: By turning Chrome into an action-taking assistant, Google is pushing browsers toward “agent” capabilities rather than pure navigation, raising expectations for rivals to add similar task automation [1][3].
  • E-commerce workflows: If Auto Browse can reliably apply discounts, manage sign-ins, and complete purchases with permission, it could shift how consumers shop online and how retailers design checkout flows [3].
  • Testing and QA: Hands-on reports showing inconsistent performance highlight a growing need for standardized evaluation of agent reliability across real websites and edge cases [2][common].

Historical Background

Web browsers have steadily added automation features such as form autofill and password managers over the past decade, reducing repetitive online work [common]. More recently, “agentic” AI assistants have expanded from chat to task execution, attempting to complete multi-step workflows across websites rather than just answering questions [common]. Google’s move embeds that agent idea directly into Chrome, using Gemini to carry out actions on the open web instead of staying inside a single app [3][1].

Action Items

  • Try Auto Browse in a low-stakes task first: If you have AI Pro or Ultra access, start with a simple shopping list or appointment request and keep the permission prompts conservative until you trust the workflow [1][3].
  • Use the disconnect controls after each experiment: Because the feature is opt-in with app-connection controls, disconnect any connected apps you no longer want the agent to access after completing a task [3].
