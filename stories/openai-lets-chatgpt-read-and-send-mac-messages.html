OpenAI lets ChatGPT read and send Mac messages

Category: Technology

OpenAI launched an Apple Messages plugin for ChatGPT on Mac that lets the chatbot search message history, summarize conversations, draft replies and send messages through Apple’s Messages app [6][9][8]. The feature works with iMessage, SMS and RCS conversations available in Messages on macOS, and the message-reading and sending functions are available in ChatGPT Work and Codex on desktop rather than regular ChatGPT chats [4][9][21]. The setup requires users to grant ChatGPT access to Messages history, Full Disk Access, contact names and automation tools, according to Engadget and MacRumors [6][9]. OpenAI told Engadget the plugin does not create an index of a user’s texts, reads past threads only when a user explicitly prompts it to use that context, and will not send a drafted message unless the user approves it [6]. MacRumors and Deccan Chronicle reported that OpenAI warns against persistent approval because it removes the final review step before ChatGPT sends a message on the user’s behalf [9][10].

Primary Source: View original article

Key Points

  • Suggested uses: OpenAI suggested prompts that ask ChatGPT to check a calendar before replying about dinner, find birthdays in messages, suggest follow-ups and identify possible spam messages [4][9][10].
  • Device limits: The Messages plugin runs on the Mac desktop app, does not work on mobile, and cannot be accessed remotely through Messages [3][7][21].
  • Public reaction: Business Insider reported immediate backlash from texters online, including privacy concerns and objections to receiving AI-written personal messages [18].

Perspectives

Ari Weinstein, OpenAI product staff: Weinstein said the integration lets ChatGPT send, read and analyze messages while allowing users to edit messages before sending.

Sources: Deccan Chronicle

Online texters: One X user quoted by Business Insider wrote, "If I find out that AI has been texting me on your behalf, I will never speak to you again."

Sources: Business Insider

Timeline

  • June 2024: Apple and OpenAI launched ChatGPT system integrations across platforms [3].
  • July 2026: Apple sued OpenAI over alleged trade-secret theft [3][9].
  • 20 August 2026: OpenAI announced the Apple Messages plugin for ChatGPT [8][9].
  • 21 August 2026: OpenAI detailed privacy controls to Engadget after launch [6].

Technical Details

  • Full Disk Access: The plugin requires macOS Full Disk Access, a system permission that lets an app read and write files beyond its normal sandbox limits [6][9][26].
  • Automation APIs: MacRumors reported that the plugin uses AppleScript and Accessibility settings, while RBC Ukraine also cited AppleScript and Accessibility as the macOS tools behind the integration [9][16].
  • Local database access: iFanr reported that the connector reads the local Messages SQLite chat database after permission is granted, then uses macOS automation mechanisms to parse and draft messages [15].

Industry Impact

  • AI agents: The Messages plugin follows OpenAI’s Computer History feature, which Business Insider said lets ChatGPT learn from actions users take in some apps and websites and is off by default [18].
  • Personal data connectors: iFanr described Messages as part of a connector strategy that also includes ChatGPT Finances through Plaid and ChatGPT Health through Apple Health and medical-record data [15].
  • Platform control: The integration uses macOS automation and accessibility mechanisms rather than an official API, leaving Apple and third-party AI developers to compete over how user data moves across apps [15].

Business Angle

  • The plugin touches private messages and relies on broad macOS permissions, putting Apple’s privacy controls under scrutiny [6][9].
  • Enterprise users may treat message-analysis tools differently from consumer users because corporate communications can trigger legal and compliance reviews [21][common].
  • The plugin shows AI assistants acting across apps, but platform owners can restrict permissions if security or privacy risks grow [15][common].

Action Items

  • Review Mac permissions: Check macOS System Settings for Full Disk Access, contact access and automation permissions granted to ChatGPT, and remove access if you no longer need the plugin [6][9].
