Perplexity moves Computer AI agent onto Macs for local execution

Category: AI

Perplexity launched a fully local mode for its Computer AI agent on Oct. 20. The mode runs the model, task planning and file processing on supported Apple silicon Macs rather than Perplexity’s servers. It is available through the Mac app to Pro, Max and Enterprise subscribers; the company recommends at least 36 GB of unified memory [2][3][5]. With user permission, the agent can work across apps including Mail, Messages, Notes and Numbers. Users can separately authorize cloud access for web searches, connected services or help from more than 15 frontier models. Perplexity says code and tool operations run in isolated sandboxes. The rollout follows its earlier local-file and hybrid modes; local Computer is now available in the latest Mac app [1][6][10].

Primary Source: View original article

As more demanding workflows become practical to run locally, the machines people already own will take on a larger share of their AI work.

— Perplexity (Engadget)

Key Points

  • Model choices: Users can download Qwen 3.6 or PPLX Pro, Perplexity’s post-trained version of Qwen, to run locally [2][7].
  • Memory limits: Apple’s M6 Mac mini tops out at 32 GB, below Perplexity’s 36 GB recommendation; the M5 Pro Mac mini can meet it in 48 GB or 64 GB configurations [5][12].
  • Hybrid option: Hybrid Compute remains available for Macs that cannot handle the fully local mode; reports cite 24 GB as its launch threshold and 32 GB as the current recommendation [2][7].
  • Security caveat: Perplexity has not specified whether Computer needs Full Disk Access; local processing does not prevent an agent from mishandling files or following malicious instructions in documents [5][12].

Perspectives

Perplexity: The company says local execution gives users more control over credit spending [6][1].

Sources: Engadget

Apple: Apple has announced plans to tighten macOS controls for Full Disk Access, requiring more explicit user action before apps receive that broad access; it has not announced when the changes will take effect [5][12].

Sources: AppleInsider

Timeline

  • February 2026: Perplexity launched Computer for Max subscribers, routing tasks to external models [7]
  • May 2026: Personal Computer added access to local Mac files and native apps [7][1]
  • September 2026: Hybrid Compute split tasks between cloud models and local processing [7][8]
  • 20 October 2026: Fully local Computer mode became available in the Mac app [2][3]

Technical Details

  • Unified memory demand: Apple silicon uses a shared pool of memory for CPU and graphics processing, and users cannot upgrade it after purchase; Perplexity has not published performance figures for full tasks across Mac configurations [7][5].
  • Model memory footprint: Perplexity’s earlier benchmark for a compressed, 4-bit Qwen 3.6-35B-A3B model used 19.4 GB on an M5 Max MacBook Pro, but the company has not identified which Qwen 3.6 size its local mode installs [7].
