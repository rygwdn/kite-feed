Microsoft expands Windows 11 update controls for users

Category: Technology

Microsoft is rolling out new Windows Update controls to people testing Windows 11 in the Dev and Experimental Insider channels, giving them more say over when updates install and when their PCs restart [1][3][4][2]. The changes include the ability to keep pausing updates in 35-day increments with no stated end point, along with tweaks meant to make shutdown and restart behavior less tied to immediate update installation [1][3][4]. That marks a notable shift from Microsoft's long-running push toward mandatory updating, with Tom's Hardware calling it the first significant loosening of that policy in more than a decade [4]. For users, the immediate benefit is more predictable PC behavior and fewer interruptions. For Microsoft, it looks like an effort to ease frustration around forced restarts while keeping Windows Update as the default maintenance system [3][1][2].

Technical Details

  • 35-day pause cycle: The new design keeps the 35-day pause unit but lets users extend pauses repeatedly, effectively removing the fixed maximum delay described in earlier Windows behavior [1][4].
  • Restart handling: The update changes how pending patches interact with power commands, with reports describing an effort to reduce the way shutdown and restart actions trigger update installation [2][3][4].

  • Software ecosystem: By reducing forced restarts, Microsoft is addressing a common Windows pain point and giving users more control over when updates interrupt their sessions [2][3].

These new Insider features stand out because Tom's Hardware describes them as the first major easing of that mandatory-update posture in more than a decade [4].
