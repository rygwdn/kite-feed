Web-testing platform Optimizely breach exposes visitors at 178 sites to malware

Category: Technology

Hackers exploited a vulnerability in website-testing platform Optimizely on Nov. 16, injecting malicious JavaScript into scripts used by 178 organizations, including the BBC, CNN, Zoom, IKEA, HSBC and Salesforce. Security researcher Scott Helme and cybersecurity firm Report URI found that the code reached visitors through Optimizely’s trusted delivery infrastructure, without requiring attackers to break into each customer’s servers [4][8][37]. The scripts attempted to replace cryptocurrency wallet addresses, capture card details entered into website forms, steal browser cookies, take screenshots and load exploit kits targeting older Apple iPhones and iPads. Report URI tracked about $7,040 in cryptocurrency sent to attacker-linked wallets in roughly nine hours. Researchers could not establish how many card details were stolen and reported no confirmed iPhone takeover in this campaign [9][10][8]. Optimizely said it patched the flaw, removed the injected code, revoked tokens and reset access for affected accounts. Salesforce disabled the scripts while investigating, and IKEA opened an inquiry. Equifax stopped using the service and said it found no evidence its systems were compromised [41][6].

Key Points

  • Affected sectors: Researchers identified 32 banking and finance organizations, 23 technology and software firms, and 20 retail and fashion businesses among the affected groups [15].
  • Payment limits: The card skimmer could read details entered into a site’s own payment forms, but researchers said hosted payment frames such as Stripe and Adyen were outside its reach [6][37].
  • Changing payload: Report URI said the malware was rebuilt 26 times on Nov. 16, and researchers examining 1,611 Optimizely scripts found malicious code in 188 [14][4].
  • Browser defenses: A review of 256 affected organizations’ web hosts found 68 without a Content Security Policy, while only 24 policies blocked the malicious payload [40].
  • Wider distribution: Hudson Rock found similar malicious code associated with Kissmetrics, StorifyMe and minute-ly, indicating the activity was not limited to Optimizely [6][33].

Technical Details

  • Project JavaScript: The attacker inserted code into an optional Project JavaScript field in customer projects. Optimizely’s unchanged snippet then delivered the code using the vendor’s domain and certificate, which affected sites already trusted [5][8].
  • Exploit targeting: Report URI described Coruna payloads targeting iOS 13–17 and DarkSword payloads targeting iOS 18. An iOS 26 component appeared to fingerprint devices rather than exploit them [43][3].
  • Content Security Policy: This browser policy restricts the sources from which a page can load scripts and the destinations to which it can send data [40].

Industry Impact

  • Financial services: HSBC said unauthorized scripts were not active on its websites [17].
  • Customer incident response: The injected code could collect card information from affected companies’ own payment forms. Security teams needed to determine which pages ran infected scripts and which payments those pages processed [37].

Historical Background

Security researcher Scott Helme said his team had first seen the injected code on Turkish websites in September, before the November campaign [37]. Apple said the underlying iOS vulnerabilities targeted by the exploit kits had been fixed last year, and users running current software were protected [17].

Q&A

Q: Could visiting a listed website alone have triggered the iPhone attack?

A: Yes. The exploit code could load through a hidden webpage element, so no download or suspicious-link click was required [3].

Action Items

  • Review card transactions: If you entered card details on an affected site on Nov. 16, check statements for unfamiliar charges and contact your card issuer if you find any [12].
  • Verify crypto transfers: Check the destination address for cryptocurrency payments made through affected sites on Nov. 16 against the address you intended to use [6][13].
  • Update Apple devices: Install the latest iOS or iPadOS version available for your iPhone or iPad; researchers specifically identified iOS 18.7.3 and iOS 26.3 as patched against the exploit chains [5][13].
