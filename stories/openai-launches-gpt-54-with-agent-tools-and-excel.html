OpenAI launches GPT-5.4 with agent tools and Excel

Category: AI

OpenAI announced GPT-5.4 on March 5 and is rolling it out across ChatGPT and its API. It’s arriving in multiple variants—including “Pro” and “Thinking”—aimed at different kinds of professional workflows [4][3]. Alongside the model release, OpenAI introduced “ChatGPT for Excel” and new financial data integrations designed to speed up modeling, research, and analysis in regulated environments—another sign of its push into business and financial-services use cases [6][1]. Coverage across outlets framed GPT-5.4 as a competitive move in a crowded premium-model market, while also spotlighting ongoing debate about pricing and how much safety documentation OpenAI is publishing for its most advanced variants [2][8][10][5].

Primary Source: View original article

Did you know: One blogger calculated a single GPT-5.4 Pro image-generation example that took 4m45s and cost $1.55—an illustration of how “premium” model usage can add up fast in heavy workflows [12].

Key Points

  • Spreadsheet integrations: OpenAI added tools that let ChatGPT work directly in Excel and Google Sheets. It also announced an “OpenAI for Financial Services” suite with partners including FactSet, MSCI, Third Bridge and Moody’s [16][18].
  • Pricing tiers: Third-party coverage described premium pricing and positioned GPT-5.4 as a direct competitor to Anthropic’s Claude, pointing to stronger coding performance as a key differentiator [8][12].
  • Spreadsheet benchmark: OpenAI leaned into spreadsheet and office-document work, with one write-up citing an internal spreadsheet-modeling benchmark score of 87.3% for GPT-5.4 versus 68.4% for GPT-5.2 [12][4].
  • Fewer mistakes: OpenAI says GPT-5.4 is 18% less likely to include any errors than GPT-5.2 and makes 33% fewer false claims than GPT-5.2 [14][25].
  • More transparent “Thinking” workflow: In ChatGPT’s Thinking mode, GPT-5.4 can outline its plan for tackling a request so users can steer it midstream. OpenAI also highlights improvements in how it navigates desktop environments when issuing mouse and keyboard actions [14].
  • Benchmarked performance: OpenAI says GPT-5.4 beat human professionals in 83% of comparisons on its GDPval benchmark, which spans 44 occupations [16][25][19].
  • Agent framing: Several outlets described GPT-5.4 as “built for agents” or a step toward autonomous agents, citing multi-step tool use and computer interaction as major enablers [9][7][3].
  • Safety documentation: OpenAI published a dedicated “Thinking” system card alongside the release, continuing its pattern of model-specific safety and risk documentation for advanced variants [5][4].

Technical Details

  • Long-context pricing step: OpenAI says GPT-5.4 supports up to 1 million tokens of context in API/Codex, but charges double per million tokens once input exceeds 272,000 tokens [18].
  • Token efficiency: OpenAI says GPT-5.4 can solve some tasks using substantially fewer tokens (reported as 47% fewer in some cases), which generally lowers inference time and API spend [18].
  • Tool and computer use: OpenAI emphasized “computer use” and “tool search” as first-class capabilities, aiming to let the model take steps across tools rather than only produce static answers [4][3].
  • 1M-token context: GPT-5.4 is described as supporting a 1 million-token context window, letting users keep much larger codebases, documents, and multi-step workflows in context than typical short-context models [4][12].
  • Native computer use: GPT-5.4 adds a “native” computer-use mode (via API/Codex) in which the model issues keyboard and mouse commands based on periodic screenshots, aiming to complete workflows across multiple applications [14][18][23].

Industry Impact

  • Financial data platforms: OpenAI’s “OpenAI for Financial Services” push bundles spreadsheet-embedded ChatGPT with finance-oriented integrations/plugins, a sign that LLM tooling is increasingly distributed through established market-data and workflow surfaces—not only standalone chat interfaces [16][18].
  • Enterprise AI tiers: Outlets describe GPT-5.4 access as skewing toward paid tiers (including higher-end Pro/Enterprise) and developers via the API, reinforcing a segmentation strategy between everyday chat use and higher-cost professional workloads [14][18][3].

Historical Background

Generative AI assistants began leaning into “agentic” features in the mid-2020s, as major vendors put more emphasis on tools that can plan and carry out multi-step tasks across apps—not just answer prompts [common]. In the days just before GPT-5.4, OpenAI shipped GPT-5.3 Instant as a faster, everyday model while positioning GPT-5.4 for heavier “Thinking” workloads, reflecting an accelerated release cadence reported across outlets [17][18].

Action Items

  • Pilot GPT-5.4 on a real spreadsheet workflow: Use ChatGPT for Excel on a copy of a financial model, then check formulas, assumptions, and outputs against your existing process before relying on results for reporting or decisions [6].
  • Set cost guardrails for long-context use: If you use the API, add token budgets and alerts—especially for prompts above ~272,000 tokens, which one analysis says can trigger higher pricing [12].
  • Try GPT-5.4 for spreadsheet modeling: If you have access to the Excel/Sheets integrations, start with a small, non-sensitive workbook (for example, a forecast or scenario model). See whether GPT-5.4 cuts down back-and-forth while keeping formulas and assumptions easy to audit [16][26].
  • Review the safety documentation for agent deployments: Read the GPT-5.4 Thinking system card, then map its risks and limitations to your internal policies before allowing tool-using or computer-using workflows in production [5].
  • Pilot computer-use workflows safely: If you’re using GPT-5.4’s computer-use mode via API/Codex, begin with a sandbox account or test environment. Validate each step before letting it operate on real production apps or data [18][23].
