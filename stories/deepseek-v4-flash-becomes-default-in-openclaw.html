DeepSeek V4 Flash becomes default in OpenClaw

Category: Technology

OpenClaw said in a Sunday update that it added DeepSeek’s new V4 Flash and V4 Pro models to its catalog, and made V4 Flash the default model for the open-source AI agent framework [1][3]. The update also added integrations including Google Meet and included workflow optimizations, as the broader tech conversation turned to DeepSeek’s latest release and its support for Huawei Ascend chips [1][2]. DeepSeek released the V4 models in preview with an emphasis on lower memory use and broader deployment options. The sources describe V4 Flash as a 284 billion-parameter mixture-of-experts model with 13 billion active parameters, while V4 Pro is the flagship model; OpenClaw says Flash can deliver performance close to Pro in its Max inference mode [2][3]. Together, those features give developers a potentially more efficient open-weight option and underscore growing interest in AI systems tuned for non-Nvidia hardware, especially Huawei’s Ascend platform [2][1].

Did you know: OpenClaw made DeepSeek V4 Flash its default model even as TechNode described V4 Pro as the much larger 1.6 trillion-parameter flagship [3].

Key Points

  • Memory drop: DeepSeek said the new V4 models cut memory requirements by 9.5 times, aiming to make deployment easier on available hardware [2].
  • Model scale: TechNode reported that V4 Pro has 1.6 trillion parameters, which helps explain why OpenClaw chose V4 Flash as a lighter default option despite similar Max mode performance [3].
  • Open weights: gHacks described both releases as open-weight preview models, giving developers more room to experiment even though full training details are not public [2].
  • Agent expansion: OpenClaw’s 2026.4.24 release also added Google Meet to the framework’s toolset [1][3].
