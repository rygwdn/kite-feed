Anthropic lets Claude users install AI-built tools as Mac and Windows apps

Category: AI

Anthropic has begun rolling out “Install as app,” a beta feature that turns eligible tools created with its Claude chatbot into desktop apps for macOS and Windows. The apps have their own icons and windows, can be shared, and can use Claude connectors. Users can build them by describing a tool in a chat, without packaging code or setting up an API key [1][3][14][17]. The apps require an internet connection and an active Claude sign-in to open, and Claude requests count against the user’s plan limits [9][5][17]. Anthropic does not review apps before installation, and users decide whether to grant access to desktop features or local files [3][14]. The beta is rolling out across Claude plans, but it is limited to the Mac and Windows desktop clients; template-based Docs, Slides and Sheets artifacts cannot be installed [3][5]. Team administrators can control full computer access, while Enterprise owners must enable the feature. Anthropic has also cautioned that users should grant broad access only to apps from authors they trust [3][17].

Primary Source: View original article

Key Points

  • Permission tiers: Apps start with browser-level capabilities. Separate permissions can enable notifications, global shortcuts or floating windows, while full access lets apps run programs and read, change or delete files [14][3].
  • Update exposure: Claude requests permission again after an artifact update, but code loaded from an external website can change without prompting for renewed approval [5][15].
  • Shared app use: People using a shared app that calls Claude sign in with their own accounts, and usage counts against their plans, not the creator’s [3].
  • Admin controls: Team plans allow installation by default but keep full computer access off until an administrator enables it; Enterprise plans have the feature disabled by default [3][2].
  • Organizational exclusions: HIPAA-ready and hybrid deployments cannot use the apps; full computer access is also unavailable to Claude for Teachers and K–12 organizations [3][5].

Perspectives

Anthropic: The company says tools people rely on for work should open like other apps and notify users when something needs attention [12].

Sources: SiliconANGLE

AppleInsider: The Apple-focused technology publication argues that mandatory internet access and Claude sign-in make the apps less useful than conventional desktop software, which can work offline [9].

Sources: AppleInsider

Technical Details

  • Client requirement: Installing an artifact as an app requires Claude Desktop for Mac or Windows version 6.28899.0 or later [3][5].
  • Authorship limits: Full computer access is generally limited to apps the user created or, for Team and Enterprise customers, apps made within their organization [14][3].
