Social media platform X suffers second outage this week

Category: Technology

X (formerly Twitter) experienced a widespread service disruption on Friday, Jan. 16, leaving some users unable to load the website or app and others seeing partial pages, blank screens, or error messages [1][2][5][7][8][9][6][4]. Multiple outlets described the problems as intermittent, with feeds sometimes stuck on older posts and some features (like Following) failing to populate [5][2][6]. By late morning in the US, X appeared broadly reachable again, while its developer/status information still indicated an ongoing incident tied to streaming endpoints and elevated errors [5]. The outage was the second significant disruption reported within the same week, and X did not immediately provide a public explanation or respond to requests for comment in several reports [2][5][8][3][9].

Did you know: Downdetector reports reflect user-submitted complaints, so the visible totals can differ from the actual number of affected customers [2].

Key Points

  • Scale of reports: Outage tracking via Downdetector showed large spikes in user-submitted reports, including more than 41,000 in the US by 10:35 a.m. ET, about 8,000 in the UK, and over 2,400 in India [2].
  • Error variety: Some users encountered Cloudflare-branded error pages, though reporting indicated the underlying issue appeared to be on X’s side rather than a repeat of prior Cloudflare problems [2][9][4].
  • Developer incident: X’s developer/status page cited an incident affecting streaming endpoints that increased errors, beginning at 7:39 a.m. PT, and later showed the issue as resolved after nearly six hours [5].
  • UI oddities: During the disruption, X’s Following feed sometimes displayed a prompt to “find some people and topic to follow,” even for established accounts, while other areas like Explore could load [5].
  • Competitor moment: Rival Bluesky users publicly joked about the outage, and Engadget noted Bluesky’s official X profile previously changed its picture to a butterfly logo in a bikini amid the week’s interruptions [5][7].

Perspectives

Technical Details

  • Streaming endpoints: X’s developer/status notes tied the incident to streaming endpoints, which support real-time delivery of posts/events to apps and third-party clients; elevated errors there can stall timelines and updates [5][common].
  • Cloudflare error pages: Some users saw Cloudflare-branded error pages, which can appear when a site’s origin servers fail or misbehave behind a CDN/reverse proxy—even if the CDN itself is not the root cause [2][9][common].
  • Crowdsourced outage tracking: Downdetector aggregates user-submitted problem reports to visualize spikes; it is useful for timing and reach signals but does not directly measure total impacted users [2][common].

Industry Impact

  • Creator workflows: When X timelines and posting fail or lag, creators and newsroom teams often shift to alternate channels (for example, Bluesky activity noted during the outage), reinforcing a multi-platform publishing habit [5][7][common].
  • Third-party developers: An incident described on X’s developer/status page suggests API or streaming reliability issues can affect tools that rely on real-time updates, from social dashboards to automation [5][common].
  • CDN attribution risk: Cloudflare-branded error pages can lead users to misattribute blame, showing how infrastructure layering can complicate incident communication for any online service [2][4][common].

Historical Background

Twitter rebranded as X in 2023 after Elon Musk’s acquisition and subsequent product changes [common]. Large social platforms typically operate on complex distributed systems where failures in critical services (such as API or streaming components) can cascade into user-facing outages [common].

Q&A

Q: Did the outage affect third-party apps differently than the main X app?

A: The only specific technical note reported was an incident on X’s developer/status page tied to streaming endpoints; the articles did not provide a detailed breakdown by third-party client [5].

Q: What evidence suggests the Cloudflare-branded errors were not a Cloudflare outage?

A: Reporting said some users saw Cloudflare error pages but described the issue as being at X itself and not a repeat of Cloudflare’s recent technical issues that previously took X offline [2].

Q: How long did the Friday disruption last according to X’s own status updates?

A: Engadget reported X updated its status page around 1 p.m. PT to mark the issue resolved after nearly six hours [5].

Action Items

  • Check X service health before troubleshooting: If X acts broken, consult X’s developer/status page for active incidents (Engadget noted it tracked the streaming-endpoint issue) before reinstalling apps or changing settings [5].
  • Enable cross-posting during outages: If you publish regularly, set up a backup channel and cross-post key updates to another platform when X is unstable; coverage described users switching to Bluesky during the interruption [7][5].
